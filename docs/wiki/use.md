# 日常使用

主页面只有一个，四个标签加一个月历：**待办、最近推送、收件箱、设置**。

## 第一次（大概五分钟）

| # | 做什么 | 在哪 |
| --- | --- | --- |
| 1 | 手机 QQ 扫码登录 | 页面「QQ 接入」那块 |
| 2 | 勾选要盯的群，保存 | 同一块下方的群列表 |
| 3 | 手机浏览器打开同一个地址，「添加到主屏幕」 | 手机浏览器菜单 |
| 4 | 订阅 iPhone 日历（可选） | 设置 →「iPhone 日历订阅」，用相机扫卡片 |
| 5 | 配 AI 摘要（可选） | 设置 →「AI 摘要」，选服务商、粘 key、保存并测试 |
| 6 | 配推送（可选） | 设置 →「提醒怎么送到手机」，照 1-2-3 填 |

不配 5 和 6 也能用：没有 AI 就走本地规则摘要，没有推送就靠网页和日历。

## 待办

按「今天 / 本周 / 逾期 / 已完成」分组，宽屏时月历在右边同屏。

- 点左边的方块打勾完成。
- 「查看完整原文」看那条群消息的原话。
- 「纠错」改摘要或分类。
- 卡片上的「紧急」可以手动标或取消，再点一次回到跟随 AI 判断。
- 「+」手动加一条。
- 「置顶」把某件事钉在右侧「置顶日程」面板里，已完成的任务要先恢复待办才能置顶。

月历每格最多显示 3 条带时刻的事项，超过显示 `+N`；点那一天会把当天全部事项展开。手机上月历默认折着，点「查看月历」展开。

## 收件箱

上半是**回溯聊天记录**：勾群、选日期，先点「① 回溯聊天记录」把消息抓下来，再点「② 提取通知」让模型逐条判定。只抓得到 NapCat 本地缓存里还剩的消息，越早越可能没了；点「探测最早时间」能看实际边界。

下半是**通知收件箱**：按「确定通知 / 疑似通知 / 已转待办」筛，可以按群、按关键词搜。每条写着判定理由和来源（AI 判定还是关键词判定）。想留的点「转成待办」，不想要的点「删除」——第一次点只提示确认，4 秒内再点一次才真删。删的是那条消息和收件箱记录，已经转好的待办留着。

## 群订阅

「QQ 接入」下面那块群列表：勾选就是订阅，取消就是不再监控，保存后立刻生效，不用重启。

白名单的意思是「只处理勾过的群」，没勾的一律忽略——所以闲聊群不会污染你的待办。

## 推送

「截止提醒」要发得出去，至少得配一个通道。设置里列了四种：WxPusher、Server 酱、PushPlus、企业微信/钉钉群机器人。点开一种，旁边写着去哪拿、复制什么、贴哪里，填完点「保存」立刻生效，再点「发一条测试消息」看手机收没收到。

输入框留空表示这项不动；页面只回显尾四位，不显示明文。一个通道都没配时，右栏「服务自检」里的消息推送会标黄，并给一个「去设置」的按钮。

## 手机端

1. 手机和电脑连同一个 Wi-Fi。
2. 浏览器打开 `http://<电脑局域网IP>:8766/`。电脑 IP 用 `ipconfig` 看「IPv4 地址」。
3. 菜单里「添加到主屏幕」，之后像 App 一样点开。

用流量访问要先开通公网入口（Tailscale Funnel），见 [常见问题](faq.md)；不开流量访问时可以关闭公网入口，关掉后手机照常走同一 Wi-Fi。

## iPhone 日历

设置 →「iPhone 日历订阅」，卡片上有一张二维码，用 **iPhone 相机**扫（别用微信扫），会跳到「订阅日历」确认页。卡片会按「公网地址 → 局域网地址」的顺序给可用地址，想换就点地址下面的「局域网 …」按钮，二维码跟着换。

手动路径：iPhone「设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历」，服务器填卡片上的地址。

同步规则：网页上标记完成的，日历里那条变成「已完成」；被忽略或过期的变成「已取消」。刷新频率由 iOS 决定，想立刻刷新就在日历 App 里下拉。

## 托管：让 NapCat 和你的电脑版 QQ 共用一台电脑

同一个 QQ 号不能在两个电脑端同时在线，这是腾讯服务端的规则。托管就是帮你轮班：开始托管先关电脑版 QQ、再启动 NapCat；结束托管停掉 NapCat、把 QQ 开回来。

三个入口效果一样：网页顶栏的「开始托管 / 结束托管」按钮、右下角托盘菜单、设置里的四个勾选框。

| 勾选项 | 默认 | 作用 |
| --- | --- | --- |
| 自动退出电脑版 QQ | 开 | 开始托管时关掉你的 QQ |
| 托管结束后恢复电脑版 QQ | 开 | 结束托管时把 QQ 开回来 |
| 启动时自动开始托管 | 关 | 一启动就进托管 |
| 开机自动启动群务台 | 关 | 写当前用户的开机启动项，不需要管理员 |
| 桌面浮球 | 关 | 打开后右下角出现浮球，点开是待处理清单；开关存本地，重启后不变 |

点「开始托管」会停顿十几秒，它在关 QQ，不是卡住。

## 桌面浮窗

默认不显示，要去「设置 → 托管设置 → 自动化选项 → 桌面浮球」打开。打开后右下角出现一个圆球，球上挂着还剩多少条待处理；点开是「待处理」面板，标题、截止时间、来自哪个群和摘要都在里面，能直接点「完成 / 稍后 / 忽略 / 置顶」。

拖动会记住位置。前台有全屏窗口时它会自动藏起来，窗口只是最大化不算全屏，照常显示。托盘菜单里的「显示/隐藏浮窗」只在开关打开时才有；把开关关掉，浮球一两秒内就收起。

## 退出

托盘图标 →「退出（结束托管并关闭）」。直接关浏览器标签页不会关掉软件，它还在后台跑。

服务要是自己崩了（不是从托盘退出的），看门狗会在 5 分钟内把它拉起来；从托盘「退出」主动关掉的不会被拉起，直到你下次自己启动。

配置项都在 [配置](config.md)，界面报错见 [常见问题](faq.md)。
