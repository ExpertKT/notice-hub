# 日常使用

主页面只有一个，四个标签加一个月历：**待办、最近推送、收件箱、设置**。

## 第一次（大概五分钟）

| # | 做什么 | 在哪 |
| --- | --- | --- |
| 1 | 手机 QQ 扫码登录 | 页面「QQ 接入」那块 |
| 2 | 勾选要盯的群，保存 | 同一块下方的群列表 |
| 3 | 手机浏览器打开同一个地址，「添加到主屏幕」 | 手机浏览器菜单 |
| 4 | 订阅 iPhone 日历（可选） | 设置 →「iPhone 日历订阅」，用相机扫卡片 |
| 5 | 配 AI 摘要（可选） | 设置 →「AI 摘要」，选服务商、粘贴 key、保存并测试 |
| 6 | 配推送（可选） | 设置 →「提醒怎么送到手机」，照 1-2-3 填 |

不配置第 5、6 项也能使用：没有 AI 就走本地规则摘要，没有推送就通过网页和日历查看。

## 待办

按「今天 / 本周 / 逾期 / 已完成」分组，宽屏时月历在右边同屏。

- 点选左侧复选框即可标记完成。
- 「查看完整原文」看那条群消息的原话。
- 「纠错」改摘要或分类。
- 卡片上的「紧急」可以手动标或取消，再点一次回到跟随 AI 判断。
- 「+」手动加一条。
- 「置顶」把某事项固定到右侧「置顶日程」面板里，已完成的任务要先恢复待办才能置顶。

月历每格最多显示 3 条带时刻的事项，超过显示 `+N`；点那一天会把当天全部事项展开。手机上月历默认折叠，点「查看月历」展开。

## 最近推送

这里存的是已经发出去的推送，只读存档。按今天 / 昨天 / 具体日期分组，一条推送一行，列出时间、类型、完整标题（折行显示、不截断），右侧是消息条数与重点条数。顶部可搜群名、标题、正文，也可按群、按类型（定时摘要 / 紧急推送 / 静默摘要）筛选。宽屏进入页面即默认选中最新一条、右栏直接显示全文，点选任一列表项即可切换；搜索或切群、切类型把当前选中筛掉时，会自动落到新列表第一条。手机端点选列表项就地展开，进入页面不自动展开。四档阅读宽度保持不变，空摘要不再占用空卡。

和收件箱的区别：收件箱放的是原始群消息，可以「转成待办」「删除」；最近推送是已经推给你的摘要存档，仅供查看，不提供处理动作。

## 收件箱

上半是**回溯聊天记录**：勾群、选日期，先点「① 回溯聊天记录」抓取消息，再点「② 提取通知」让模型逐条判定。只抓得到 NapCat 本地缓存里还剩的消息，时间越早越可能已被清除；点「探测最早时间」可查看实际边界。

下半是**通知收件箱**：按「确定通知 / 疑似通知 / 已转待办」筛，可以按群、按关键词搜。每条写着判定理由和来源（AI 判定还是关键词判定）。需要保留的点「转成待办」，不需要的点「删除」——第一次点击只提示确认，4 秒内再点一次才实际删除。删的是那条消息和收件箱记录，已经转好的待办留着。

## 群订阅

「QQ 接入」下方的群列表：勾选即订阅，取消即停止监控，保存后立即生效，无需重启。

白名单的意思是「只处理勾过的群」，没勾的一律忽略——因此闲聊群不会进入待办列表。

## 微信来源

微信来源读取本机加密的聊天数据库，解密密钥由 AI 助手或手动流程写入 `.env` 的 `NOTICEHUB_WECHAT_KEY`；首选让 AI 助手代做，把设置页里那句可整句复制的话转发给它，手动流程作为兜底。微信 4.1 起密钥换成了「内存里一块异或配置」的存法，程序会按这块配置的形状把它找出来再校验；4.2 实测能读出群和消息，4.3.8 还没拿到回执。

拉取后，选择区分成两部分：上方是「AI 建议订阅」推荐区，可折叠，按类别分组，每行列出人数与 AI 给出的理由；下方是「全部群聊」，默认收起，可按名字搜索，逐个勾选。顶部显示「共 N 个群 · AI 建议 K 个 · 已选 M 个」。

勾选只改变本地待保存状态，点「保存」才提交。AI 不可用时显示「关键词建议」并保留「重新识别」；一个群都没拉到时，页面给出三步自查与「再试一次」。

钉钉使用同一套选择区；拉不到名字的会话显示「未命名会话（前 6 位 cid）」。

## 推送

「截止提醒」要能发出，至少需要配置一个通道。设置里列了四种：WxPusher、Server 酱、PushPlus、企业微信/钉钉群机器人。点开一种，旁边说明获取位置、复制内容与填写位置，填完点「保存」立即生效，再点「发一条测试消息」确认手机是否收到。

输入框留空表示该配置保持不变；页面只回显尾四位，不显示明文。一个通道都没配时，右栏「服务自检」里的消息推送会标黄，并给一个「去设置」的按钮。

## 手机端

1. 手机和电脑连同一个 Wi-Fi。
2. 浏览器打开群务台显示的地址。同一 Wi-Fi 下用电脑的局域网 IP（`ipconfig` 看「IPv4 地址」），端口以界面「服务端口」一行为准。
3. 菜单里「添加到主屏幕」，之后可像 App 一样打开。

用流量访问要先开通公网入口。入口和两条通道的对比都放在「设置 → iPhone 日历订阅」卡里：默认 **Cloudflare 快速通道**，不用注册账号、不用域名；想要重启也不变的固定地址，切成 **Tailscale**（要登录你自己的 Tailscale 账号）。要不要注册、地址重启后是否变化、要不要装客户端、首次开通多久、哪个更快、失败怎么办，卡里逐项列了结论。当前地址与端口由群务台显示，不要照示例端口填。不使用流量访问时可以关闭公网入口，关掉后手机照常走同一 Wi-Fi。

## iPhone 日历

设置 →「iPhone 日历订阅」，卡片上有一张二维码，用 **iPhone 相机**扫描（不要用微信扫描），会跳到「订阅日历」确认页。卡片会按「公网地址 → 局域网地址」的顺序给可用地址，需要更换地址时点下方的「局域网 …」按钮，二维码随之更新。

手动路径：iPhone「设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历」，服务器填卡片上的地址。

同步规则：网页上标记完成的，日历里那条变成「已完成」；被忽略或过期的变成「已取消」。刷新频率由 iOS 决定，需要立刻刷新可在日历 App 中下拉。

## 托管：让 NapCat 和你的电脑版 QQ 共用一台电脑

同一个 QQ 号不能在两个电脑端同时在线，这是腾讯服务端的规则。托管即由程序代为切换：开始托管先关电脑版 QQ、再启动 NapCat；结束托管停掉 NapCat、把 QQ 开回来。

三个入口效果一样：网页顶栏的「开始托管 / 结束托管」按钮、右下角托盘菜单、设置里的四个勾选框。

| 勾选项 | 默认 | 作用 |
| --- | --- | --- |
| 自动退出电脑版 QQ | 开 | 开始托管时关掉你的 QQ |
| 托管结束后恢复电脑版 QQ | 开 | 结束托管时把 QQ 开回来 |
| 启动时自动开始托管 | 关 | 一启动就进托管 |
| 开机自动启动群务台 | 关 | 写当前用户的开机启动项，不需要管理员 |
| 桌面浮球 | 关 | 打开后右下角出现浮球，点开是待处理清单；开关存本地，重启后不变 |

点「开始托管」后会停顿十几秒，此时正在关闭 QQ，并非卡住。

## 桌面浮窗

默认不显示，需在「设置 → 托管设置 → 自动化选项 → 桌面浮球」中开启。打开后右下角出现一个圆球，球上挂着还剩多少条待处理；展开后是「待处理」面板，标题、截止时间、来自哪个群和摘要都在里面，能直接点「完成 / 稍后 / 忽略 / 置顶」。

拖动后的位置会被记住。前台有全屏窗口时它会自动藏起来，窗口只是最大化不算全屏，照常显示。托盘菜单里的「显示/隐藏浮窗」只在开关打开时才有；关闭开关后，浮球一两秒内收起。

## 设置页怎么找东西

设置项按用途收成四组：**接入与通道**（首次配置、QQ、订阅群、钉钉、微信、学习通、推送）、**提醒与订阅**（日历、手机、托管、外观）、**系统与维护**（版本更新、备份、运行信息、洞察、实验功能、服务自检）、**关于**（关于、支持）。默认只摊开第一组，点组标题就开合，展开状态记在这一页里，切走再回来不会弹回默认。「托管状态」那张实时摘要卡不进组，一直留在最上面。

三种找法都能直达：上面六个常用磁贴、左栏分组导航、左栏顶部搜索框。它们都会先把目标那一组摊开再滚过去，所以不会落到一张收起来的组上。搜索命中几项会写在输入框下面，没命中的组会整组收起来。

## 外观：字号、配色、主题

设置 →「外观」最上面是字号，三档：

| 档位 | 正文 | 说明 |
| --- | --- | --- |
| 默认 | 15px | 原来的大小 |
| 偏大 | 约 19px | 字、按钮、间距一起放大 1.25 倍 |
| 很大 | 约 22px | 一起放大 1.5 倍，适合离屏幕远或看不清小字 |

改完立即生效，不用刷新，也不用保存。这个选择只记在这一台设备的浏览器里，换台电脑或换个浏览器还是默认档。放大时按钮、输入框、图标框和页边距跟着一起长，不会出现「字变大了挤在原来的小格子里」。选放大档，内容区也会跟着放宽——字大了，每行字数和屏幕两边的留白一起变化，大屏上看着更满；窗口或手机不够宽时自动撑满，不会挤出横向滚动条。改完字号页面停在原处，不会跳到别的设置块。同一张卡片里还有主题（浅色 / 深色）、强调色和通知色调。

## 退出

托盘图标 →「退出（结束托管并关闭）」。直接关闭浏览器标签页不会关闭软件，服务仍在后台运行。

服务若自行崩溃（非从托盘退出），看门狗会在 5 分钟内将其重新拉起；从托盘「退出」主动关闭的不会被拉起，直到下次手动启动。

配置项都在 [配置](config.md)，界面报错见 [常见问题](faq.md)。

## 操作补充

### 一键接入（首次使用）

1. 双击 `QQ-Notice-Hub.exe`：它会启动服务、打开页面，并在右下角放一个托盘图标。
   - 首次启动 Windows 防火墙会弹窗问「是否允许访问」，请勾上「专用网络」并点「允许访问」。手机扫码配对和「iPhone 日历」小节中的订阅操作都需要它；点了「取消」手机就连不上。
2. 页面顶部「接入状态」里选**登录方式**：
   - **扫码登录（推荐）**——用手机 QQ 扫屏幕上出现的二维码；
   - **用指定 QQ 号快速登录**——填 QQ 号，免扫码登录。**第一次用必须先扫码登录过一次**，之后这个号才会被记住。
3. 点「启动 NapCat 并登录」：程序自己找到你装好的 NapCat，用**独立资料目录**启动它，并自动写好上报地址、端口和 token。
4. 二维码出现后用手机 QQ 扫码；登录成功后勾选要接入的群，点保存。

程序不替你装 QQ；没检测到 QQ 时会给出「下载官方 QQ」按钮和三步引导（下载 → 装完不用打开 QQ → 点「重新检测」）。装了还是提示未找到：在 `.env` 里加一行 `QQ_DIGEST_QQ_EXE=<QQ.exe 完整路径>` 重启再检测；QQ 装在 `Program Files` 下时需要管理员权限运行。没装 NapCat 也能用：点击「自动下载并安装 NapCat」，程序会下载 `NapCat.Shell.zip` 并解压到 `<数据目录>\napcat`，不会动你电脑上自己的 QQ；不想要了就删除这个文件夹，等于卸载。NapCat 上游 2026-11-12 已经停更并删光了 release，程序改从社区留档取同一个包，并核对内置的 SHA-256 才解压——如果你想自己核对，指纹写在 `docs/wiki/guides/napcat-setup.md` 里。手工配置 NapCat 仍可作为备选，详见 `docs/wiki/guides/napcat-setup.md`。

> **为什么用「独立资料目录」**：NapCat 内部也是一个 QQ 客户端，如果它和你自己装的 QQ 共用同一份登录数据，它就会直接接管你的号。群务台启动的 NapCat 用单独的资料目录，**不读也不动你本来的 QQ 数据**。
>
> **同一 QQ 号不能在两个电脑端同时在线**（腾讯服务端规则，改不掉）。所以要么 NapCat 用你的号挂机、你日常改用**手机 QQ**；要么给机器人申请一个 **QQ 小号**，你自己的号照常登。想让「你的号」和「NapCat」自动轮班，看「托管：让 NapCat 和你的电脑版 QQ 共用一台电脑」小节。


**手动加高置顶日程面板**：面板下方有一条「拖动调整高度」。按住它上下拖动就能改高度（把下面的 QQ 接入面板往下挤，它不要紧）；键盘也能用：聚焦后上 / 下方向键各 24 像素，按住 Shift 变成 64 像素，Home / End 直接到最小 / 最大，双击恢复默认。高度会记住，下次打开网页还是这么高。


**今日概览里的「最近到期 / 正在进行」**：概览顶部有两个小按钮。**最近到期**（默认）按日期轮播：今天有哪些还没到点的、明天有什么、往后排；鼠标移上去或键盘聚焦时暂停轮播，左右箭头可以手动翻。**正在进行**只挑「**现在这个点正在发生**」的事——它会从通知原文里找起止时间（例如 `13:30-14:55`、`10:00-24:00`），只有当前时刻落在时间段里、而且是今天的待办才会出现，每条后面标着几点结束；原文里只有单个时刻（例如「周五 15:15 到礼堂」）或者没写时间段的不算「正在进行」，它们仍然在「最近到期」里。选哪个会被记住，刷新后还是你选的那个；「正在进行」一条都没有时会显示「现在没有正在进行的日程」，按钮不会消失。


### 公网订阅与重订

公网订阅地址 = 公网入口给出的地址 + `/calendar.ics?token=<TOKEN>`：

```text
https://随机名.trycloudflare.com/calendar.ics?token=<TOKEN>   # Cloudflare（默认）
https://你的机器.xxx.ts.net/calendar.ics?token=<TOKEN>        # Tailscale（要固定地址时）
```

它由当前公网通道转到本机 `127.0.0.1:<端口>/calendar.ics`。`?token=<TOKEN>` 不能省略；本机或同一局域网内仍使用上面的 `http://127.0.0.1:<端口>/...` 或 `http://<局域网IP>:<端口>/...` 地址。不要把公网地址改成别的端口或路径。

**地址会不会变**：Cloudflare 的地址每次重启服务都会换，换了就按下面的步骤重订；Tailscale 的地址固定，重启、换 Wi-Fi 都不变。

**开通公网的前提**：Cloudflare 不用账号，在设置里点「开通公网」，等待分配地址即可。Tailscale 要先在 Tailscale 登录页用你自己的账号登录一次、并开通 Funnel，此步骤无法由程序代劳。两条都没开通时，页面上只有局域网地址，手机用流量打不开。

如果换过 token、日历内容长期不更新，或者旧订阅里看不到带具体时刻的新日程，按下面顺序重新订阅：

1. 在 iPhone「设置 → 日历 → 账户」里删除旧的已订阅日历。
2. 用 Safari 打开上面的公网地址，确认能拿到日历文本；如果打不开，先排查电脑服务和网络，不要直接重复添加订阅。
3. 回到网页「设置 → iPhone 日历订阅」，用 iPhone 相机扫描卡片上的二维码添加；也可以复制带 token 的订阅链接手动添加。
4. 在「日历」App 里勾选新订阅。

订阅日历不保证跟着「设置 → 日历 → 获取新数据 → 每 15 分钟」刷新；iOS 会按自己的计划获取订阅。需要马上看新任务时，在「日历」App 里手动下拉刷新。

如果日历里看不到带时刻的日程，先在电脑打开 `http://127.0.0.1:<端口>/api/health`；看到 `{"ok": true, "service": "qq-tasks"}` 才说明服务正在运行。服务日志在 `安装目录\logs\qq-live-digest.log`。旧版本导出的 ICS 缺少 `VTIMEZONE`，iOS 会丢掉这类带时刻的日程；当前版本已加入 `Asia/Shanghai` 的 `VTIMEZONE`，因此不要用旧订阅内容判断新版本是否正常，按上面的步骤重订。

#### 学习通

1. 在电脑浏览器登录学习通，在「设置」→「学习通」点「自动获取学习通 Cookie」。程序会尝试读取本机浏览器里已保存的登录状态，并先拉取课程验证；验证成功后才保存到本机数据目录，不会写进 `.env`。
2. 若自动获取提示失败，请保持浏览器已登录学习通后重试。仍失败时，展开手工方式：在浏览器打开开发者工具的「网络」面板，选择一条已登录页面请求，从请求标头复制 `Cookie` 的完整值，粘贴到下方 Cookie 框，再点「保存学习通设置」。Cookie 只保存在本机数据目录，页面和接口不会回显其内容。
3. 点「拉取我的课程」，勾选要订阅的课程，点「保存学习通设置」。只读取这些课程的通知和作业截止时间，不会提交作业或修改学习通内容。
4. Cookie 可能过期。过期后待办页顶部会出现红色提示；重新登录学习通后，再点自动获取，或按上面的手工方式更新。设置页会显示上次同步时间和 Cookie 状态。

Cookie 仅保存在本机数据目录的 `data\chaoxing.cookie`，不会显示在页面响应或写入 `.env`。请像密码一样保护它，不要发给别人。


### Windows 11「智能应用控制」拦住了启动器

- **现象**：双击 `QQ-Notice-Hub.exe`（或点「一键接入」调起的引擎）窗口一闪就没，安全中心提示「智能应用控制已阻止」。它拦的是**没有签名的可执行文件**，不是杀毒报毒。
- **原因**：Win11 22H2 之后的 Smart App Control 只放行有可信签名/云信誉的程序，本项目没有商业代码签名，当前也没有办法绕过。
- **怎么办（从简单到麻烦）**：
  1. 关掉这项策略：设置 →「隐私和安全性」→「Windows 安全中心」→「应用和浏览器控制」→「智能应用控制」→ 选「关闭」。注意：**关掉之后系统一般要求重装 Windows 才能重新开启**，自己权衡。
  2. 只对这一个文件夹放行：同样页面里把「评估」模式打开，等待其学习几天，之后再运行一次；或把解压目录加进 Microsoft Defender 的排除项。
  3. 换一台没开这项策略的电脑，或改用「源码运行」（见 [安装与升级：从源码跑](install.md#从源码跑)）。
- **不要用管理员 CMD 里的二维码去扫**：用管理员权限启动的控制台字体/字间距会变，NapCat 在窗口里画的二维码会变形扫不出来。直接开群务台的网页，扫**网页上的二维码**——那是从 NapCat 的 `qrcode.png` 读出来重新渲染的，跟控制台字体无关。

### 服务会不会自己死掉（看门狗）

新版 `QQ-Notice-Hub.exe` 会看护内层 `qq-live-digest.exe`：启动器每 2 秒检查一次服务；服务退出后按 5 秒、15 秒、45 秒退避重启。重启期间网页和公网日历可能短暂打不开，等待自动恢复即可。

实测：2026-10-08 20:28 强杀内层服务（PID 45464）后，7.4 秒自动重起（PID 54908），8766/8765 恢复监听，`/api/health` 返回 200，启动器自身 PID 不变。

如果反复重启或一直打不开，查看：

```text
安装目录\logs\launcher.log
```

日志里会有类似「服务退出：pid=… code=…」的记录；服务本身的运行日志仍在 `安装目录\logs\qq-live-digest.log`。

## 九、出货包怎么用（发给别人 / 换电脑）

1. 解压 `QQ-Notice-Hub.zip`（解压后 `QQ-Notice-Hub.exe` 就在你选的那个文件夹里，没有多余的子文件夹）
2. 双击 **`QQ-Notice-Hub.exe`**
   - 会自动生成 `.env`、启动服务、打开浏览器、在桌面建一个「notice-hub」快捷方式
   - 右下角出现托盘图标，软件就在后台跑着了
   - 首次启动会要几秒
   - Windows 防火墙弹窗请点「允许访问」（勾上「专用网络」），手机才能连上
3. 之后按「第一次（大概五分钟）」小节走一遍
4. 想关掉：**托盘图标 →「退出」**

> 升级（覆盖安装）：把新压缩包里的文件覆盖到原目录即可，`.env`、`data`、`logs` 会保留。
> 覆盖前请先从托盘退出（或结束 QQ-Notice-Hub.exe 进程），否则被占用的 `qq-live-digest.exe` / `QQ-Notice-Hub.exe` 会覆盖失败、报「拒绝访问」。
> 如果覆盖时报「拒绝访问 / Access is denied」，多半是旧目录里有个文件被设成了只读——
> 右键那个文件 →「属性」→ 取消勾选「只读」→ 确定，再覆盖一次即可。

> 包里的 `qq-live-digest.exe` 是主程序，不要单独双击它（要通过 `QQ-Notice-Hub.exe` 启动）。
> 数据存在同目录 `data\`，想备份就备份这个文件夹。
> 托盘不在了但进程还在（极少见）：任务管理器里结束 `QQ-Notice-Hub.exe` 即可。

### 升级/更新

两条路，任选一条。

**一、让软件自己更新（推荐）**

1. 打开网页 →「设置」→「版本更新」，点「检查更新」。
2. 有新版本时卡片里会列出**新增功能**和**修复问题**（就是这一版 release 的说明原文），旁边有「查看完整更新说明 ↗」跳去 GitHub。
3. 点「下载更新包」→ 确认 → 它只下载并校验新包，**不会自己安装**。下完后点右下角托盘图标 →「重启并更新」，约 10–30 秒换好，再刷新网页即可。
4. 启动时如果发现有新版本，页面顶部也会出现一条「发现新版本 vX」的横幅，点「点这里更新」直接跳到那张卡片。横幅可以关掉，关掉后同一个版本不再提示。

更新期间别关机、别退出托盘。数据不会被覆盖：`data\`（消息、待办、Cookie、日历链接）和 `.env` 原样保留，安装包只覆盖程序文件。

**二、手动覆盖安装（自己下载 zip）**

1. 下载新的 `QQ-Notice-Hub.zip`。
2. 先通过托盘菜单「退出」关闭 `QQ-Notice-Hub.exe`。
3. 把新包解压并覆盖到原安装目录（例如 `安装目录`）。
4. 覆盖时保留原目录里的 `.env`、`data\` 和 `logs\`，不要删除或改名。
5. 重新双击 `QQ-Notice-Hub.exe`，等待网页打开。

只要 `.env` 里的 `QQ_DIGEST_WEB_TOKEN` 没变，手机网页和 iPhone 日历订阅地址里的 token 就没变，不需要重新订阅；如果 token 改过，必须按「公网订阅与重订」小节删除旧订阅并重新添加。

网络不通（检查更新失败）不影响使用，隔一会儿再点一次；一直不行就走「二、手动覆盖安装」。

> 发版的人请注意：release 正文按 `## 新增功能` / `## 修复问题` / `## 已知问题` 分节、条目用 `- ` 开头，
> 网页会照这个结构把「新增功能」「修复问题」分成两栏显示。没有分节的老 release 会整段原文显示，不会报错。

## 十、用哪个大模型

**推荐做法：到页面右上角「设置」→「AI 摘要」中完成配置即可，不用改 `.env`。**

1. 在「用哪一家」下拉里挑一个：**智谱 GLM** 和 **硅基流动** 有长期免费的模型，**DeepSeek** 最便宜（一个月通常不到一元钱），**阿里云百炼**新用户送 100 万字。
2. 点那个「打开拿钥匙的页面」，照着链接旁边写的 1-2-3 步注册并复制那串钥匙。
3. 把钥匙粘到「钥匙」框里，点「保存并测试」。测试通过会显示模型回的那句话；没通过会告诉你是钥匙不对、还是网络不通。

选好服务商以后，接口地址和模型名已经替你填好了，不需要懂它们是什么。想手工配置、或者想换成下拉里没有的服务商，再按下面的表改 `.env`：

| 后端 | 说明 |
|------|------|
| **云 API（机器上没有大模型就用这个）** | 在 `.env` 里填 `QQ_DIGEST_LLM_ENDPOINT=` 和 `QQ_DIGEST_LLM_API_KEY=`，任意 OpenAI 兼容服务都行（DeepSeek、硅基流动、DashScope…）。免费层与低价选项见 [接入 API 指南](guides/api-integration.md) |
| `auto` | **默认**。先试 CodeBuddy/WorkBuddy CLI（消耗你的账号额度），没装 CLI 或调用失败会自动回退本机 Ollama |
| `ollama` | 只用本机 Ollama 模型，免费、不出网 |
| `codebuddy` | 只用 CodeBuddy，失败就报错 |

改 `.env` 里的 `QQ_DIGEST_LLM_BACKEND=` / `QQ_DIGEST_LLM_ENDPOINT=`，然后重启程序即可。（设置页里保存过的服务商同样写进 `.env`，两种方式不会打架。）

**关于读图**：群里的图片要变成文字，得端点本身提供视觉模型。设置页里选的服务商如果支持读图，「保存并测试」下面会写「（能读图片）」；显示「不能读图片」时，图片会**只记录不识别**——不报错、不白花 token，日志提示一次。要重新读图，就在 `.env` 里显式写出该端点支持的视觉模型：

```ini
QQ_DIGEST_VL_MODEL=该端点支持的视觉模型名
```

## 十二、开机自启与看门狗

在管理员 PowerShell 中，从项目目录执行注册脚本（默认就是脚本所在目录，也就是解压 zip 后的文件夹；路径含空格时请用引号）。脚本会自动判断启动方式：解压出来的安装目录用同目录的 `QQ-Notice-Hub.exe`（自带看门狗），源码目录用 `run.ps1`。先空跑看一眼，不写任何东西：

```powershell
.\install-task.ps1 -InstallDir '安装目录' -WhatIf
```

确认输出的 `Execute`/`Arguments` 是你要的，再去掉 `-WhatIf` 真正注册（`-NapCatExecutable` 默认取安装目录下的 `NapCat.Shell.exe`，装在别处才需要显式指定）：

```powershell
.\install-task.ps1 -InstallDir '安装目录' -NapCatExecutable 'C:\Program Files\NapCat\NapCat.Shell.exe'
```

脚本幂等地创建三个任务：`NapCat-QQ`、`QQ-Live-Digest`、`NapCat-QQ-Watchdog`。卸载命令：

```powershell
.\uninstall-task.ps1
```

验证命令与预期输出：

```powershell
Get-ScheduledTask -TaskName 'QQ-Live-Digest'
# State 应为 Ready 或 Running
Get-ScheduledTask -TaskName 'NapCat-QQ','QQ-Live-Digest','NapCat-QQ-Watchdog' | Select-Object TaskName,State
```

看门狗任务会在服务任务不处于 Running 时启动 `QQ-Live-Digest`。需要定期清理旧备份时先预览：

```powershell
.\tools\cleanup-install.ps1
```

确认清单后再执行 `tools/cleanup-install.ps1 -Apply`；默认是 dry-run，`-WhatIf` 可显式保持预览模式。

#### 钉钉

1. 在这台 Windows 电脑上安装并登录钉钉桌面客户端。群务台读取钉钉本机保存的数据，不需要企业应用或管理员权限。
2. 打开「设置」→「钉钉」，勾选「启用钉钉」，点「拉取我的群」，勾选要订阅的群聊，再点「保存钉钉设置」。
3. 群务台只读取勾选群聊，不会向钉钉群回发消息。状态行只会出现四种：没开钉钉是「未启用」；正常监听是「已连接实时监听 N 个群」；勾了「启用钉钉」但监听没起来是「钉钉已启用，监听未启动」；勾了启用但一个群都没勾是「已启用，但还没勾群」。

钉钉卡片上勾了「启用钉钉」就立即生效并存盘，不用再点「保存钉钉设置」（和微信一致）；改订阅群、填别名才需要点保存。

钉钉客户端大版本升级后，本地数据库格式可能变化，读取功能届时可能暂时失效；确认客户端已登录并更新群务台后再检查状态。

#### 微信：读本地数据库

微信数据库是加密的，程序需要从微信进程内存读取解密密钥。首次读取群名时会扫描内存，通常约 3 分钟；这可能被微信判定为异常，存在触发风控甚至封号的风险。请先评估账号风险，再决定是否启用。

| 方式 | 要复制什么 |
|------|------------|
| 一、WxPusher（微信，推荐） | 应用Token + 我的 UID（要给一群人推送时再加话题 ID） |
| 二、Server 酱（微信） | 密钥一份 |
| 三、PushPlus（微信） | 用户token 一份 |
| 四、企业微信 / 钉钉机器人 | 群机器人的那条地址，整段粘贴 |

保存、测试消息、密钥回显与未配置提示见前面的「推送」小节；要清空配置可点「清空重填」。

- 不配推送也能用：快捷操作里的「显示订阅二维码」，用手机日历扫描，到期日程会同步进手机自带日历。
- iPhone 日历订阅不依赖推送通道，它由 iOS 按自己的节奏刷新。
