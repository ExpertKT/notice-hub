# 更新日志

按版本倒序，一条版本一节，写用户视角——这一版你手上的东西变了什么。

最新版本看代码里的 `noticehub/version.py`。发版时把「未发布」整理成新的一节。

## 未发布

- 讲安装、NapCat 接入和自动更新的地方，都补了一句「建议让 agent 来装」。这几步最容易卡住，交给 agent 跑比自己对着文档点省事。
- 那句提示旁边还能点「什么是 agent」看一段解释；「设置 → 版本更新」里也有一块同样的提示，讲清为什么更新这一步值得交给它。
- 托盘「重启并更新」以前每次都失败，会让人反复重下几十兆，现在能正常装上了。
- 更新通道改成一个开关，点一下就生效，不用再点「保存通道」；失败了会把选中项退回去并说原因。
- 检查更新失败不再静默：页面会说清是网络、镜像还没同步，还是清单对不上。
- 二维码读不出来不再只显示破图，会把原因写在二维码下面；换码失败也会给下一步。
- NapCat 的报错不再把人往错方向带：token 不一致就说 token，端口被占就说端口，不再一律让人去查目录权限。
- 连点两次「重启并更新」不会再起两个安装脚本抢着覆盖文件；第二次会直接说「正在安装更新，请等它跑完」。
- 停引擎没停干净时会说出是哪个进程还在，不再报一句成功就完事。
- 引擎正在跑的时候改了接入配置，页面会提示「配置已写入，重启引擎后生效」，不会再让你对着改了没反应的界面猜。
- 桌面浮窗重新打开了：右下角一条细边，鼠标靠近变成小球，点开是今天要办的事。配色换成和网页同一套。
- 浮窗展开后右边不再被切掉：125% 缩放的屏上，以前面板只画出 288 宽（内容 360 宽），标题尾巴和右边那个「稍后」都被裁了；现在窗口按内容原尺寸摆，整块都在。
- 桌面浮窗换成了网页版：收起是右下角一个圆球，上面挂着还剩多少条待处理；点开是「待处理」面板，标题、截止时间、来自哪个群、摘要都在，完成 / 稍后 / 忽略 / 置顶直接在里面点。
- 浮窗以前在有些机器上只出一个空白方块：打包自带的运行环境让浏览器的渲染进程起不来，窗口在、内容全白。现在能正常加载了。
- 球右上角那个红数字以前被圆形裁掉一半，现在整颗露出来。
- 顶栏铃铛去掉那圈边框，跟旁边几个按钮一样，鼠标移上去才有底色。未读提醒也从数字改成一个小红点：99+ 之后数字没意义，还挤铃铛；条数在点开的面板里。
- 「快捷操作」五个按钮回到靠左排，和卡片内边距对齐。
- 顶栏右边那组按钮前面补了一道竖分隔线，和左边品牌与页签之间那道对称。
- 卡片和按钮的圆角改成连续曲率（苹果那种从直边平滑过渡的圆角），看着更软；浏览器不支持时自动退回普通圆角。
- 文档里的 macOS 部分撤下了：还没适配，安装脚本留着但没验证过。
- 桌面浮球改成默认关闭，想用再打开：「设置 → 托管设置 → 自动化选项 → 桌面浮球」，勾上就出现，取消后一两秒内收起；开关状态记在本地配置里，重启后不变。以前开过浮球的机器升级后球会收起来，去这个开关重新勾上就行。
- 浮球不再被最大化窗口挡住：以前前台有铺满屏幕的窗口时会被当成全屏游戏藏起来，其实只是最大化，现在照常显示。
- 开通公网入口不再「显示成功但手机连不上」：以前只要 Tailscale 说规则写进去了就报成功，其实后台还没放行、或者这条地址反代到了别的地方；现在会真的从公网地址访问一次，通了才算开通，不通就直接告诉你卡在哪一步。
- 浮球后面的黑块没了：以前那是个网页窗口，画不出透明底，所以球和面板外面总拖着一块黑；现在换成自己画窗口，球和面板外面是真的透明，底下的桌面和视频照常露出来。
- 浮球展开收起不再「啪」一下换画面：现在是球慢慢长成面板、收起来再缩回球（展开 180 毫秒、收起 140 毫秒）。
- 浮球面板待办超过 6 条时以前看不到第 7 条，现在面板里能往下滚。
- 浮球上的铃铛图标补回来了：界面重做时弄丢了，现在又画在球上。取不到待办时角标会画一个「!」——以前取失败和「真的没有待办」都显示 0，长得一模一样。
- 铃铛面板里的通知留得住了：以前通知卡 6 秒就自己消失，面板里最多留 3 张，第 4 条一来就把最旧的挤掉，点开铃铛常常只剩一两张；现在留 12 张，公告也不会自动消失。
- 公告刷新失败不再把列表清空：以前公告接口一次请求失败，整个列表就被清空，下次成功又全回来；现在失败就留着上次的列表，只在角落说一句没刷新成功。
- 铃铛面板从铃铛下面展开：以前面板从视口顶端掉下来、右对齐内容区，跟铃铛没什么关系；现在贴着铃铛下方展开，下面放不开就翻到上方。展开收起也有过渡了。
- 公网入口能关了：以前只有「开通」，开了就关不掉；现在已开通状态有「关闭公网」，点了要确认，关掉后手机用流量打不开，同一 Wi-Fi 下照常用。

## 1.1.0-beta.18 · 2026-11-05

这一版只修一处提示：设置页把早就装上的旧包当成「更新包已就绪」。

- **「更新包已就绪」不再报一个早就装上的旧版本。** 待装记录只在「包比当前版本新」时才算数。以前下载过、后来手动覆装或者从别处装了新版的，那条记录会一直留着，设置页和托盘就跟着喊「更新包已就绪（旧版本号）」，点下去还把旧包又装一遍。现在启动时按版本号比一次，不比当前版本新的记录直接清掉；比当前新的照样留着。
- **最近推送的卡片标题改用正文第一句。** 以前一屏卡片全叫「定时摘要 / 静默摘要」，看不出哪条讲什么；分类名留在上面那行小字，正文里不再重复这句。
- **手机宽度下的大标题不再剩一两个字单独占一行。**

## 1.1.0-beta.17 · 2026-11-04

界面按原型收口的一版：提示与引导都收进右上角悬浮通知，通知颜色可以自己挑。

**同一批还修了收件箱、设置、通知栏这一圈报上来的十条，另外把同一个毛病的其它地方一起找了。**

- **设置页不再自己跳回顶上。** 以前重进设置、或后台定时刷新数据时，整页内容会被先清空再重建，文档高度一塌到底，浏览器顺势把滚动条夹到最上面。现在清空期间先把设置页的高度锁住，重建完再放开并把位置校回去；带锚点的链接也不会再跳到隐藏页签里、把页面拽回顶部。
- **微信/钉钉的群列表不再被挤成一列竖字。** 「我的群」那行本来是横向排的名称加按钮，群列表被塞进同一行，只剩几像素宽，群名逐字换行。列表现在单独占一行；学习通的课程列表和自动配置块同样处理。
- **通知不再盖住页面内容。** 右上角那叠通知以前固定在页面上、不占位置，会压住月历表头和右侧数字。现在收进「通知 / 公告」面板：点铃铛才展开，两个页签分开装，面板自己有滚动条，不再浮在正文上面。
- **铃铛以前根本点不开。** 它被包在一个带 `hidden` 的容器里，全项目没有一处去掉这个 `hidden`。这次一起修了；窄屏下它排在底部导航里。
- **快捷操作五个按钮居中。** 以前从左边排起、右边空一截。
- **最近推送的列宽可以调了。** 新增四档：窄 / 标准 / 宽 / 通栏，选择记在这个浏览器里，下次打开还是那档。两处写死的宽度合并成一个变量，标题和正文不会再出现宽度不一致。
- **收件箱默认不再刷一屏「[图片]」。** 这类条目正文只有一个占位符，本身没字可读。新增「内容类型」筛选：全部 / 文字 / 图片 / 链接 / 文件，默认隐藏「判定为噪声、且去掉占位符后一个字都不剩」的那些；想看就点这一排最后的「含占位符」，它和类型筛选可以叠加。标签上的数字跟同一个口径走，不会再出现「标签写 12 条、点进去 0 条」。
- **QQ 接入的二维码真的会换了。** 以前点「刷新二维码」只是把同一张图重新下载一遍，码早过期也看不出来。现在等扫码状态下点它会先让引擎重启、重新出码，再取新图；失败会把原因写在二维码下面，不再假装刷过。
- **置顶日程的拖动把手居中了。** 以前那道短横线偏在一侧。
- **切页不再抖。** 页面留出固定的滚动条位置，页签切换时不会因为滚动条出现或消失而左右跳；切到内容更短的页签时明确回到顶部，不再停在半空。
- **两处「先清空再取数」改掉了。** 切到「最近推送」、或刷新收件箱时，列表原先会先被清空再等接口回来，中间那一瞬高度塌陷、滚动位置被夹走——和设置页那条是同一个机制。现在拿到数据再一次性换入，失败也保留原来的列表。
- **顺手清掉三处空转。** 一个从未定义过的缓动变量让复选框的过渡整段失效；一处加了类名却没有对应样式，导致完成任务时要空等 200ms；还有一个切页「运镜」函数设置了变量却没有任何样式消费它。
- **通知同时挂着三张时，页面会卡死，这条是真卡死。** 通知栈最多三张，满了就挤掉最旧的一张；但挤这个动作只在「会自动消失」的卡里找，碰到三张都不会自动消失的（例如重要公告 + 体检提示 + 关键故障）就一张都挤不掉，判断「满了」的那个循环于是永远成立，整个页面主线程被转死——表现是点一下之后页面彻底不响应、刷新才好。现在找不到可挤的就退而挤掉最旧那张，并给这个循环加了次数上限兜底。

**这一轮把提示和引导收进「右上角悬浮通知」，页面更安静。**

- **服务公告不再占页头横幅。** 「【重要】beta.16 存在收件箱误判……」这类公告改成右上角悬浮通知，排在「还有 N 项没配好」的上面；点通知打开原来的公告详情弹窗，必须确认的公告没有 ×、不会自动消失。拉取失败时也会在同一位置出一条可关闭的提示，下一次拉取成功会自动撤掉、恢复真实公告。
- **公告详情弹窗支持 Esc 关闭。** 按 Esc 等于点「我知道了」，关掉就算看过，下次启动不会再弹同一条。
- **「开始使用」改成首次打开才弹。** 不再是一张常驻页面的卡：第一次打开软件（没点过「别再提醒」）时弹出来，看完可以随时关掉，不再把首页内容顶到一屏之下。
- **通知卡换成真正的磨砂玻璃。** 半透明底 + 背景模糊，能透出底下的纸纹与内容；透明度按试用反馈调到 56%，深浅主题都重新校过文字对比度。
- **通知颜色可以自己挑。** 设置 → 外观里「强调色」下面新增「通知颜色」：跟随纸面 / 鼠尾草 / 梅紫 / 赭橙 / 黛蓝 / 石墨，只影响右上角的悬浮通知，颜色会和纸面自动调和，玻璃质感不变。选择记在这个浏览器里。
- **页签抬头只留大标题。** 「最近推送 / 收件箱 / 设置」抬头上面那行小字（eyebrow）按需求去掉了。
- **新手引导文案跟着新入口改。** 「点顶栏开始托管」「右栏订阅群」这类过时说法改成「设置 → 托管设置 / QQ 接入 / 订阅群」，引导按钮会先跳到设置页再高亮目标。
**界面换成了纸感编辑风。** 配色、导航、卡片形状整体重做：暖纸底、沙色细线、鼠尾草绿做强调，顶栏收成一条浮在页面上的窄岛。功能一个没少，位置变了不少。

- **顶栏变成浮岛。** Logo 和四个页签收进同一条窄栏，浮在页面上方。滚动时它一直在，下面的内容不会被它压住。（公告铃铛与托管开关这轮移出了浮岛，见下。）
- **配色换成纸墨四色。** 页面底 #EDE7D6、卡片 #FBF8F0、边框 #8C8168、文字 #3A3A28，强调色是鼠尾草绿 #5C6B44。深浅两套都重新算过对比度：正文对卡片 10.9:1、次要文字 6.9:1、分隔线 3.6:1，都过 WCAG。
- **背景从「流动柔光」换成纸纹。** 原来底色上有两层慢慢漂移的青绿光晕，现在整页铺一层极淡的纸纤维颗粒（固定层，不拦点击、不吃性能），纸感更安静。
- **按钮改成方形圆角。** 以前全是胶囊形，现在按钮、页签、输入框都是长方形加圆角；胶囊只留给状态标签、版本徽标、进度条和开关。卡片不再有可见阴影，靠一道沙色细线分界。
- **右栏四块搬进主列做了 bento。** 置顶日程、本周小结、快捷操作、服务自检不再挤在右侧长条里，改成主列上两行两格的方块，只在「待办」页签出现；月历跟在待办分组后面。
- **QQ 接入与订阅群搬进设置页。** 设置页改成「左侧分组导航 + 右侧面板」：接入与通道、提醒与订阅、系统与更新三组，点左边跳到对应面板。
- **今日概览保留成一块。** 大标题、完成度、最近到期/正在进行的切换、进度条和「清空已完成」还在同一张卡里，只是换成了衬线大标题；轮播从固定 200px 高的方块改成横向滑动的卡片带。这块卡只在「待办」页签出现（见下）。
- **月历格子只留圆点。** 有事项的日期格里画小圆点（一件一个，最多三个），不再挤小字事项和「+N」；点一下日期格（或键盘回车）在下方展开当天全部事项与截止时刻，再点一下收回。
- **主题多了一档「跟随系统」。** 设置 → 外观里从两档变三档，选了跟随系统，系统切深色页面就跟着变，不用刷新。
- **强调色可以自己挑。** 设置 → 外观里新增五个色点（鼠尾草、梅紫、赭橙、黛蓝、石墨），点一下全站的主按钮、选中态、焦点环一起换，选择记在这个浏览器里。
- **版本号从页头挪到了设置页。** 顶栏不再显示 beta 徽标，位置更清爽；版本号和推送通道、服务端口一起放在「运行信息」里。
- **品牌副标题删除。** 顶栏只留 Logo 和「群务台」三个字，浮岛高度收到 44px。
- **浮球页同步换色。** 桌面浮球和面板用同一套纸墨配色，暗色也一起改了。

**这一轮把界面按 `b-integrated` 原型逐项对齐，改的是形状与位置，不是功能。**

- **Logo 换成原型的三色。** 墨橄榄圆做底、纸色圆点压在右上、鼠尾草绿做内圈、纸色对勾；服务端注入的品牌色（`--brand-ink` / `--brand-accent`）仍然生效。
- **浮岛只留 Logo 和页签。** 公告铃铛的入口先空着（公告面板与接口都没动，只是没挂在浮岛上）；托管状态和「开始托管」按钮搬进设置页。
- **设置页多了「托管状态」卡。** 设置页右列第一块就是它：状态按钮点开还是「开始使用」引导，旁边的「开始托管 / 停止托管」照旧。
- **「关于与支持」搬进设置页。** 原来挂在待办页末尾，现在是设置页右列最下面一块，左侧子导航里能直接跳过来。
- **当天事项详情不再套卡片。** 去掉了卡片边框和底，只留一道虚线顶边 + 衬线日期标题 + 件数小字；右上角的关闭从图标换成「收起」两个字。
- **各处尺寸按原型收紧。** 卡片、按钮、页签、输入框、日历格统一到一套更紧的圆角与高度（卡片/按钮 10px、页签 30px 高、按钮 28px 高、小按钮 24px、输入框 28px 高）；待办卡悬停只横向错开 2px，不再抬阴影。
- **单文件演示页签修好了。** 本地生成的那份单文件演示页（不入库）双击打开时不再被首装向导浮层盖住，四个页签可以正常点。

**界面几何换成了一套设计令牌。** 样式段里不再散落随手写的像素值，圆角、间距、字号、层级各有一套刻度，改一个变量就能整体挪动。这是为以后重做界面打底的第一版。

- **圆角收敛到四档。** 以前同一个界面里有 2 / 3 / 4 / 5 / 6 / 7 / 8 / 9 / 10 / 12 / 14 / 16 / 18 / 20 / 25 / 99 / 999 这么多圆角值，同一种元素在不同面板里长得都不一样。现在按原型只留：控件 6、卡片与按钮 10、浮岛与概览 14、胶囊 999（正圆 50%）。16px 见方的复选框和柱状图底部另有 4px 与 2px 的固定小圆角，不再参与分档。
- **间距统一到 4 的倍数。** 卡片之间、卡片内边距、标题与内容之间这三种关系，桌面和手机上用的是同一个刻度。手机端以前会把内边距收到 12/8，现在和桌面一致——同一种关系在不同宽度下应该读起来是同一种节奏。

**NapCat 拉不起来时不再假装成功。** 上次退出留下的 QQ 进程常还挂在同一个数据目录上，这时再点「启动并登录」，新的启动器会把参数交给它然后自己退出，以前照样返回成功，用户只看到二维码不出来。现在启动前先清掉占着这个目录的残留 QQ 进程（只清命令行里带本安装目录的，同机上别人的 QQ 不碰），起来之后再看一眼它是不是还活着，秒退就直说原因并提示点「重启引擎」。

**结束托管时，电脑版 QQ 没真的起来会说出来。** 以前拉起进程就报成功，用户以为自己的 QQ 回来了，其实它可能被安全软件拦住、启动即退。现在等两秒再看一眼，退了就返回失败并写明原因。

**「启动成功」一律改成看结果。** `AGENTS.md` 新增一节：进程、端口、文件、请求四类动作，返回成功前必须观察到真实效果；空壳判定要带时间门槛；清理只按本安装目录匹配；失败不许沉默；同一事实只能有一个答案；修复必须锁住失败路径。

**接收端的健康检查不再报假健康。** 以前健康提供方自己抛异常，接口照样回 `ok: true`，页面显示在线、消息却进不来。现在服务还在跑仍是 200，但响应体里 `ok` 变假并带上原因。

**微信某个数据库分片读不出来时不再永久丢消息。** 取密钥失败或解密失败的分片以前被直接跳过，然后照样把「已处理」的签名记上，下一轮判定没变化、再也不读它——那段时间的消息就永远丢了。现在坏掉的分片不推进签名，下一轮继续重试，日志里写明是哪几个分片。

**数据库损坏隔离没搬干净时不再硬建新库。** 以前 `-wal`/`-shm` 移不动只记一条 warning，日志照样说「已隔离、新库已建立」，接着在原路径建库——没搬走的坏文件就被盖掉了。现在只要有一个文件没搬走就报错停下，原文件原样保留，并在提示里说明是哪个文件被占着。

**配置体检读不到 `.env` 时不再假装「都是默认值」。** 以前文件被占用或没权限，体检会把每一项都报成默认值，看起来像你没配过。现在这些项标成「未知来源」，并在说明里写清是配置文件读不出来以及原因。

**界面上、公告里、文档里的中文重写了一遍。** 原来那些「这一版没有新功能，重点是…」式的自我总结、「快了一大截」式的表功、金句收尾和「首先/其次/综上」全删了，改成直说做了什么、点了哪、看到什么。功能没动。

**代码和测试都换成了这个项目自己写的版本。** 跟上游同名文件逐行比过，最长连续相同的行不超过 6 行；77 个测试文件的用例名与条数经机器核对，一条没少。功能、配置、界面、数据结构与 beta.15 一致，升级不用重新配置。

**许可说明简化了。** 安装包和网页里不再出现「上游部分适用 MIT，详情见 NOTICE」这类声明，只保留本项目自己的 PolyForm Noncommercial 1.0.0。

**新增接口文档。** 仓库里第一次有 `docs/api.md`：HTTP 接口、命令行、全部配置项逐条列出。

**接口文档补了两处写错的地方。** `/api/meta` 实际是 15 个字段且不带 `ok`，`/api/setup/status` 顶层只有 `{ok, platforms}`；文档按代码改正。

**学习通的设置现在会存下来。** 以前在网页里开关学习通、改它的群名单，只改内存，重启就回到 `.env` 里的旧值；现在这两项和微信、钉钉一样写回 `.env`。这个毛病从有学习通那天就在，这次一起修了。

**安装包补齐了网页资源。** 页面图标和 PWA 清单以前没打进安装包，从源码自己打包出来的版本会启动失败；现在整个 `web_static` 目录都随包带上。

**安装目录里的名字统一了。** 命令行程序从 `qq-live-digest.exe` 改成 `noticehub.exe`，日志从 `qq-live-digest.log` 改成 `noticehub.log`，开机自启的任务从 `QQ-Live-Digest` 改成 `NoticeHub`。老的自启任务会在安装时自动删掉，不会出现开机跑两个实例。桌面快捷方式指向的启动器仍是 `QQ-Notice-Hub.exe`，没动。

**配置项换了前缀，老配置照读。** 环境变量从 `QQ_DIGEST_*` 改成 `NOTICEHUB_*`；你 `.env` 里原来那些旧名字仍然生效，程序会提示一次「检测到旧环境变量名」，想换就换、不换也能用。

**设置页能看配置从哪来的。** 新增配置体检：每个关键项显示当前值、来源（环境变量 / `.env` / 默认值 / 自动探测）以及有没有被覆盖。端口被环境变量顶掉这类问题，现在一眼能看出来。顶部横幅点开就是「还差什么」的列表，配好一项就少一项。

**服务没了会自己回来。** 计划任务每 5 分钟跑一次 `tools/watchdog-task.ps1` 探 `/api/health`，没应答就隐藏拉起 `QQ-Notice-Hub.exe --no-browser --from-watchdog`。从托盘点「退出」会写 `%LOCALAPPDATA%\NoticeHub\manual-exit.flag`，写了就不再拉起；下次正常启动把它清掉。

**看门狗装上会被确认。** `install-task.ps1` 把 `NapCat-QQ-Watchdog` 的触发器改成「开机跑一次 + 之后每 5 分钟一次」（`PT5M`，无限期）。`-WhatIf` 会把每个触发器打印出来，注册完回查 `Get-ScheduledTask` 才报成功。

**安装脚本现在会把看门狗任务真的建成。** 以前触发器里写了任务计划不接受的重复时长上限，`Register-ScheduledTask` 直接抛错、任务建不出来，而这个错在提权窗口里看不见，用户以为装好了其实没有。现在只设置「每 5 分钟重复」、不写上界，就是无限期重复；注册完会回读任务与重复间隔，回读不到就报错停下，不再当成装好。

**看门狗启动时不再闪黑框。** 看门狗任务改成经 `wscript` 调 `tools/run-hidden.vbs` 无窗口拉起脚本，不会再每 5 分钟闪一下黑框；原来的 `powershell -WindowStyle Hidden` 仍会先建一个控制台再隐藏。

**附件不再拿旧的凑数。** 以前文件在、大小大于 0 就算有了；现在要等于附件记录的大小且不超过上限，对不上就删掉重下。

**群建议统一按开关判断。** `suggest()` 和 `suggest_for_source()` 以前一个看 `llm_enabled`、一个看 `llm_active`，现在都看同一个开关。

**实验功能出错会说是什么错。** 底层异常不再一律糊成「尚未就绪」，现在带上异常类型。顺手修好 `GET /api/lab/search`：以前门面没把消息库路径传给 `noticehub.search`，这个接口一直 503。

**钉钉接收端返回入库条数。** `scan_once()` 以前返回读到的条数，现在返回真正入库的条数。

**数据库操作以真实结果为准。** `mark_delivery`、`clear_tasks`、`clear_finished_tasks` 改用 `rowcount` 报数；超星同步状态超过 1000 条会告警，并返回被截断的条数。

**安装演练不再把失败当成功。** `tools/e2e-install.ps1` 原来 5 处空 `catch {}` 会吞掉失败；现在停进程后复查、JSON 解析失败直接 `FAIL` 并以非零退出。
