# 群务台 wiki

群务台（notice-hub）盯着你订阅的几个 QQ 群，把「什么时候交、要做什么」挑出来，变成待办和日历事件。消息、待办、附件默认只存在你这台电脑上。

这一页只负责把你送到对的地方。

## 三条最常走的路

| 你想干的事 | 去哪 |
| --- | --- |
| 第一次装，从解压到扫码登录 | [安装与升级](install.md) |
| 已经装好了，想搞明白页面怎么用 | [日常使用](use.md) |

## 一分钟了解它的边界

- 只读群消息。不会替你发消息，不会改你的 QQ 设置。
- QQ 接入靠 NapCat，NapCat 是第三方协议客户端。登录主号有风控风险，用小号更稳。
- 电脑关机或休眠时收不到消息，开机后只补最近 24 小时。
- Linux / macOS 能跑服务，但没有托盘，自动更新也不完整。差异见 [安装与升级](install.md)。
