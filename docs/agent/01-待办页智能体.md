# 待办页：概览时间轴 + 智能体对话

这一份取代 `00-多端方案.md` 里「待办页不要聊天框」那一条。其余端（浮球、托盘、手机壳）仍按那一份，这一轮只改桌面待办页。

## 待办页只留两块

页签顺序：待办、详情、最近推送、收件箱、设置。「详情」插在「待办」右侧、「最近推送」左侧。

待办页从上到下只有：

1. 待办概览卡片
2. 智能体对话，占满卡片下面剩下的高度

待办页本身不能上下滚动。概览里的待办卡可以横向滚动。对话记录在对话框内部滚动。其它页签仍按原来的页面滚动。

从待办页拿掉这些，不再占位：

- 「最近到期 / 正在进行」两个按钮，以及「正在进行」那一栏
- 概览底部的进度条和右侧「清空已完成」
- 置顶日程、本周小结、快捷操作三张卡片
- 页顶那句「所有待办都清空了」（接口里的句子还在，给今况和对话用，页面上不再单独做一块）

「清空已完成」挪到「详情」页，仍是点两次才真的清。置顶按钮留在每张待办卡上。

## 待办概览

标题由「今日概览」改为「待办概览」。

时间轴在卡片内，一条青绿（`--teal`）。今天和明天各占一段；再往后，每个有待办的日期单独一段。色条宽度等于这一天待办卡排开的宽度，不拉满整张概览。

| 段 | 放什么 | 标签 |
|---|---|---|
| 今日 | 截止日是今天的，以及所有已逾期、还没完成的 | 今日 |
| 明日 | 截止日是明天的待办 | 明日 |
| 更远 | 每个更晚的截止日各自一段；没写截止日的归在最后 | 这一天写成「M月D日」；没有日期就写「以后」 |

色条下面是原来的待办卡，样式不改，左上角不再放打勾（和「完成」重复）。大标题是从群通知里收出的一句：事项、时间、地点。参加对象、请假和举行次数不进标题，原文仍在「查看完整原文」。今日或明日没有事项时，不写「今日」「明日」「没有」，这段收成一个圆角方块：边长等于色条高度，圆角和色条相同。方块彼此之间、方块和旁边色条之间的间距是 `--space-1`。没有更远的日期、也没有没写日期的待办时，不写「以后」，也不写「没有」。没写日期的待办仍归在「以后」。

卡片多到超出概览时，在概览上用滚轮前后滚动来左右看，不放滚动条。标题留在原处。一天里面的卡片、单张卡片都不自己横滑。同一排卡片上的「完成」「忽略」「置顶」贴在卡片底部，内容少的卡片不会把按钮顶上去。拿走一张卡时，它先淡出，接着后面的卡片向前补位，上面的色条同时变长或变短。系统「减少动态效果」不跳过这一次。

## 详情

月历、「已过期」、「已完成」都在这一页。这两段进来就是展开的，点标题可以收起，再点打开；刷新页面时保持刚才的开合。不另做「只看本周」的过滤。

## 对话

对话框在概览下方，贴底有输入框、发送、语音。配了模型钥匙之后，说出一件要做的事就会写进同一张待办表，改标题、改时间和删除见 `02-长对话.md`。没配钥匙时仍按下面的固定说法。

语音用浏览器自带的语音识别，语言中文。按钮是话筒图标。这台浏览器没有这个能力时，按钮停用，提示「不能语音输入」，不上传录音。输入框和对话是同一块底，不再另垫一条深色。发送键和话筒一样高。

刚进页面时，输入框缩在对话区中间，圆角是满圆，没有发送键，也没有对话记录。上次说过的话先备着，点开输入框才出现。「待办N件」写在对话卡片左上角，一开始就在，不跟输入框一起移动，也不被藏起来。这个数字是概览上正在显示的待办张数：今天空了、后面还有一张，就显示 1，不拿今况里「今天」那一档。待办每次重画都会重算。

点一下输入框或话筒后，唤醒是一条输入条从中间落到对话底部，不是两套输入框交叉替换：

- 约 640 毫秒，曲线是先快后慢的三次减速，后半段仍能看出在移动。系统「减少动态效果」不跳过这一次，否则点一下只会突然出现在底部。
- 动的是输入条自己的布局盒子（位置、宽度、内边距），不用变换。变换时输入光标不会跟着走。
- 对话记录晚 80 毫秒：淡入，并上移 8 像素。
- 发送键晚 160 毫秒：宽度和透明度从 0 长到原来的尺寸，避免一下子把输入框挤短。
- 过程中不换输入框、不改已有的光标位置。「待办N件」不参加这一次。

这一轮它能改的数据只有现成的待办接口，改完立刻重画时间轴：

| 你说 | 它做 |
|---|---|
| 今天 / 有哪些 / 待办 | 按三段念出标题，不改数据 |
| 逾期 / 已完成 / 待确认 | 念出这一类的标题，不改数据 |
| 完成 / 忽略 / 确认 / 稍后 / 恢复 关键词 | 对上那一条，走待办原有的完成、忽略、确认、稍后、恢复 |
| 置顶 / 取消置顶 / 紧急 / 取消紧急 关键词 | 改这一条的置顶或紧急 |
| 改期 关键词 今天或明天，或带上日期 | 改这一条的截止时间 |
| 新建 内容 | 建一条待办；内容里写了「明天」或「今天」就带上那天的截止 |
| 删除 关键词 | 先复述，原话再说一次才删 |
| 清空已完成 | 先说明会清掉什么，原话再说一次才清 |

对不上时只回复能说的这几句，不假装已经改过数据。匹配到多条时先问是哪一条，不一起改。改完马上重画时间轴。

开关 `NOTICEHUB_AGENT_SHELL` 默认是开的，写成 `0` 才关。打开时，对话的第一句用今况那句。关掉时对话照常，只是没有这句开场。
