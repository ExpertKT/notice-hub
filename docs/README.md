# docs

这里放开发说明、用户文档、产品截图和内部归档，开发者、用户和发布流程分别读取不同子目录。

| 子目录/文件 | 作用 |
| --- | --- |
| `DEV.md` | 按文件、调用链、数据和改动场景说明如何开发。 |
| `wiki/` | 用户文档和长期使用说明；发布时镜像到 GitHub Wiki。 |
| `screenshots/` | 产品界面截图，用于文档和验收参考。 |
| `internal/` | 开发过程资料、QA、交接和旧方案只读归档，不随包发布。 |

常见改动：开发流程或模块职责改 `DEV.md`；用户配置、接口、安装和使用改 `wiki/` 对应页并更新 changelog；截图更新只改 `screenshots/`。本目录文档不替代代码测试。
