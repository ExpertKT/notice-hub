# 用户可见错误文案审计（1.1.0-beta.11）

范围：会直接出现在用户眼前的错误文案——`qq_live_digest/*.py` 的 `error=` / `raise ...Error("...")` 里最终会回给页面的句子，以及 `web_static/page.html` 里写死的中文提示。内部日志、单测断言、开发期异常不算。

判定口径：用户看到这句话时，能不能**知道发生了什么 + 下一步点哪里**。含变量名/路径占位符/错误码/英文术语/HTTP 细节/一次给三个动作的，都算问题。

**本文只列不改。**

行号基于 2026-10-24 工作区（beta.11 未提交改动已在位）。

## 合计

- 用户可见错误文案：**25 条**（A 组 11 条、B 组 5 条、C 组 9 条）。
- 其中优先级最高（用户装机第一步就会撞上）：A 组 `:24-28`、`:718`、`:748`；B 组 `:2851`；C 组 `:517`。
- 三条共性问题：①路径/环境变量名/错误码直接外露；②一句话给两到三个动作，没说先做哪个；③同一个错误后端写一份、前端 `friendlyError` 再抄一份，改一处另一处不改。
