桌面浮窗 · 两种收起态

Edge 应用窗口不能像素级透明，所以不模拟玻璃球。下面比较贴边竖胶囊与圆角贴纸卡；切换方案只改变收起形状，展开列表和交互相同。点右下预览窗可展开，拖顶部短横纹可移动。

窗口妥协说明　示意采用不透明卡片底色，匹配 Edge + Win32 去边框窗口能力。原型里的窗口尺寸调整仅是浏览器内展示；正式宿主负责对同一个窗口 resize/置顶/窗口级拖动。数据为假数据，只用 summary / text / deadline / urgent / source。

方案对比

方案 A · 贴边竖胶囊（推荐）

收起 64×148px，贴屏幕右侧；显示角标、最近摘要和青绿图标。长条轮廓和边缘位置容易记，收起时已有摘要，减少打开确认成本。

方案 B · 圆角贴纸卡

收起 72×72px，18px 圆角，显示图标与数字。更像独立品牌贴纸，识别鲜明、占地小，但摘要需点开才可读。

同一窗口展开

两方案均从当前收起尺寸展开到 380px 内容宽；锚定屏幕右下角，宿主调整同一个窗口边界，内容节点不重建、不跳滚动位置。

拖动与减少动态

顶部短横纹是固定拖动区；暗色沿用现有主题 token。系统减少动态时取消窗口/内容过渡和吸附回弹，状态改用文字与数字表达。
