# notice-hub · 使用说明

把课程群里的通知自动变成「待办 + 截止时间」，在电脑、手机上都能看，并同步到 iPhone 日历。

---

## 一、它替你做了什么

- 盯着你订阅的 QQ 群，把「@全体成员」「老师发的通知」这类消息挑出来
- 交给大模型归纳成一句人话（谁要做什么、什么时候交），并**猜出截止时间**
- 存进本地数据库，同时出现在三个地方：
  1. **电脑网页**：待办清单 + 月历
  2. **手机网页**：同一个网址，可加到桌面像 App 一样用
  3. **iPhone 日历**：订阅一个 `.ics` 地址，作业自动出现在系统日历里
- 网页上还有一个**通知收件箱**：能把 NapCat 本地缓存里的聊天记录按群、按时间段整段回溯出来，逐条判定成「确定通知 / 疑似通知 / 其他」，你翻到哪条想留，点一下就能转成待办

它**只读**群消息，不会替你发消息、不会改你的 QQ 设置。没有本地模型时，可按 [接入 API 指南](接API.md) 选择免费层或低价云 API。

---

## 二、我现在要做什么（就这些）

### 第一次（只做一次，5 分钟）

| # | 要做的事 | 在哪做 |
|---|---------|--------|
| 1 | 扫码登录 QQ（就是你自己那个号） | 打开「接入向导」页面，用手机 QQ 扫屏幕上的二维码 |
| 2 | 勾选要监控的课程群 | 同一个页面上，勾完点保存 |
| 3 | 把网址加到手机桌面 | 手机浏览器打开网址 → 分享/菜单 → 「添加到主屏幕」 |
| 4 | 订阅 iPhone 日历 | 网页「设置」→「iPhone 日历订阅」：用手机相机扫卡片上的二维码；不想扫码就照第六节手动粘地址 |

### 一键接入（首次使用）

1. 双击 `qq-live-digest\QQ-Notice-Hub.exe`：它会启动服务、打开页面，并在右下角放一个托盘图标。
2. 页面顶部「接入状态」里选**登录方式**：
   - **扫码登录（推荐）**——用手机 QQ 扫屏幕上出现的二维码；
   - **用指定 QQ 号快速登录**——填 QQ 号，免扫码登录。**第一次用必须先扫码登录过一次**，之后这个号才会被记住。
3. 点「启动 NapCat 并登录」：程序自己找到你装好的 NapCat，用**独立资料目录**启动它，并自动写好上报地址、端口和 token。
4. 二维码出现后用手机 QQ 扫码；登录成功后勾选要接入的群，点保存。

程序不替你安装 QQ（你本来就有）。没装 NapCat 也能用：点击「自动下载并安装 NapCat」，程序会从官方 GitHub 下载约 1 MB，安装到 `<数据目录>\napcat`，不会动你电脑上自己的 QQ；不想要了就删除这个文件夹，等于卸载。手工配置 NapCat 仍可作为备选，详见 `docs/napcat-setup.md`。

> **为什么用「独立资料目录」**：NapCat 内部也是一个 QQ 客户端，如果它和你自己装的 QQ 共用同一份登录数据，它就会直接接管你的号。notice-hub 启动的 NapCat 用单独的资料目录，**不读也不动你本来的 QQ 数据**。
>
> **同一 QQ 号不能在两个电脑端同时在线**（腾讯服务端规则，改不掉）。所以要么 NapCat 用你的号挂机、你日常改用**手机 QQ**；要么给机器人申请一个 **QQ 小号**，你自己的号照常登。想让「你的号」和「NapCat」自动轮班，看第十一节「托管」。

### 日常（什么都不用做）

开着电脑就行。程序在后台跑，新通知会自己变成待办。你只需要：

- 想看的时候打开网页 / 手机 / iPhone 日历看一眼
- 做完的打勾（网页上点一下，iPhone 日历里那条会变成「已完成」）

### 需要注意的

- **电脑要开着**，且 NapCat（QQ 登录态）要保持在线；电脑关机/休眠期间不抓消息
- 晚上 23:00–07:00 是免打扰时段，不推送
- 群里发的**文件**（PDF/Word/Excel）会自动读内容，但图片里的文字读不了（没装视觉模型）

## 三、页面在哪里（现在只有一个页面了）

把 `<TOKEN>` 换成你的访问口令（在 `.env` 的 `QQ_DIGEST_WEB_TOKEN`，或启动器自动生成写在同目录 `.env` 里）。

| 用途 | 网址 |
|------|------|
| **主页面**：今日概览 + 待办 / 最近推送 / 收件箱 / 设置 四个标签 + 月历 | `http://127.0.0.1:8766/?token=<TOKEN>` |
| iPhone 日历订阅地址 | `http://127.0.0.1:8766/calendar.ics?token=<TOKEN>` |

> 旧地址 `http://127.0.0.1:8766/setup?token=<TOKEN>` 和 `http://127.0.0.1:8766/calendar?token=<TOKEN>` 仍然能用，它们会自动跳到主页面，不用改收藏夹。

> 手机和电脑不在同一个 Wi-Fi 时，iPhone 订阅要用电脑的 Tailscale 地址（见第六节）。

## 四、电脑端怎么用

浏览器打开主页面，顶部有四个标签：

| 标签 | 里面是什么 | 能做什么 |
|------|-----------|---------|
| **待办** | 今天 / 本周 / 逾期（默认收成一行，点开才看）/ 已完成，宽屏时月历就在右边同屏 | 点左边的方块打勾完成；「查看完整原文」看原始消息；「纠错」改摘要或分类；卡片上的「紧急」可以手动标 / 取消（再点一次回到跟随 AI 判断）；「+」手动加一条 |
| **最近推送** | 最近推给你的每一条（类别 / 时间 / 正文） | 看历史推送，没有零值空行 |
| **收件箱** | 上半「回溯聊天记录」，下半「通知收件箱」 | 见下面两段 |
| **设置** | QQ 接入、订阅群、托管、动态效果、iPhone 日历订阅 | 见第五、六、十一节 |

**回溯聊天记录**（收件箱上半）：先勾要查的群（可「全选 / 清空」），再选开始 / 结束日期（或点「最近 7 天 / 最近 30 天 / 全部可用」），点「① 回溯聊天记录」把消息抓进本地；然后点「② 提取通知」让大模型逐条判定。点「探测最早时间」可以先看每个群能回溯到多早。

> 只能回溯到 **NapCat 本地缓存**里还留着的消息，不是完整聊天史。缓存会被 QQ 自己清理，越早的消息越可能已经不在了。

**通知收件箱**（收件箱下半）：按「全部 / 确定通知 / 疑似通知 / 已转待办」筛选（按钮上带条数），还能按群筛、按正文关键词搜。每条显示判定理由和来源——来源会如实写明是「AI 判定」还是「关键词判定」。点开「查看消息原文」看原话，想留就点「转成待办」。

**置顶日程**：想让某件事一直留在眼前，在待办卡片上点「置顶」。它会固定显示在右侧「置顶日程」面板里（宽屏时在月历右边、QQ 接入上面），点摘要能跳回原卡片，点面板里的「取消置顶」就移出去。已完成的任务不能置顶（先「恢复待办」再置顶）。手机端窄屏时，面板排在月历下面。

**手动加高置顶日程面板**：面板下方有一条「拖动调整高度」。按住它上下拖动就能改高度（把下面的 QQ 接入面板往下挤，它不要紧）；键盘也能用：聚焦后上 / 下方向键各 24 像素，按住 Shift 变成 64 像素，Home / End 直接到最小 / 最大，双击恢复默认。高度会记住，下次打开网页还是这么高。

**月历怎么看**：日期格里最多显示 **3 条**当天有截止时刻的事项（每条前面是时刻，例如 `23:59 …`）；当天超过 3 条会显示 `+N`。想知道某天到底有多少件，**点那个日期格**（键盘可用 Tab 移到格子后按回车），格子下方会展开当天全部事项，面板右上角有「关闭」按钮，再点一次这个日期格或按 Esc 也能收起。当天日期格有加粗边框。**手机上**月历默认是折起来的（窄屏一格只有 40 多像素，放不下带时刻的日程），点标题右边的「查看月历」展开、再点「收起月历」折回。

**今日概览里的「最近到期 / 正在进行」**：概览顶部有两个小按钮。**最近到期**（默认）按日期轮播：今天有哪些还没到点的、明天有什么、往后排；鼠标移上去或键盘聚焦时暂停轮播，左右箭头可以手动翻。**正在进行**只挑「**现在这个点正在发生**」的事——它会从通知原文里找起止时间（例如 `13:30-14:55`、`10:00-24:00`），只有当前时刻落在时间段里、而且是今天的待办才会出现，每条后面标着几点结束；原文里只有单个时刻（例如「周五 15:15 到礼堂」）或者没写时间段的不算「正在进行」，它们仍然在「最近到期」里。选哪个会被记住，刷新后还是你选的那个；「正在进行」一条都没有时会显示「现在没有正在进行的日程」，按钮不会消失。

**页面背景**：整页有两层缓慢流动的背景（本页两个强调色的长椭圆柔光沿对角线慢慢漂移，互质的 52 秒 / 68 秒周期，所以不会看出循环），很淡，只在卡片缝隙和页边能看出来，不影响阅读；在「设置 → 动态效果」里关掉动画或系统开了「减少动态效果」时它会完全静止。背景只是观感，不影响任何功能。

**右侧三块面板**（宽屏时在「QQ 接入」下面）：

| 面板 | 里面是什么 |
|------|-----------|
| **本周小结** | 本周一到周日的到期条数（今天那根加粗），上面三个数字 = 当前待办 / 已完成 / 逾期 |
| **快捷操作** | 「新建待办」就地展开小表单：填「待办内容」（限 200 字）+ 可选的「截止时间」，保存后立刻进对应分组（不填截止时间就放进「以后」），`Esc` 或「取消」收起；「复制今日清单」把今天的待办按「时间 · 标题」复制成纯文本，直接贴到微信或备忘录；「导出日历 .ics」下载一份日历文件；「显示订阅二维码」跳到设置里的订阅卡片；「暂停动态效果」＝设置里那个开关；「回到顶部」 |
| **服务自检** | 五行状态灯（QQ 登录 / 引擎托管 / 公网日历 / 最近同步 / 本机服务），哪一项不对就在下面写明怎么修，不用猜；「重新检测」随时重跑，「打开日志」看运行日志 |

> 「服务自检」里的「公网日历」显示「只有局域网地址」时，说明 Tailscale 没连上，手机用流量就读不到订阅——照它给的提示修即可。

**动态效果**：「设置」里可以暂停呼吸/轮播这类动效（开关只保存在这个浏览器里）。如果系统开了「减少动态效果」，程序会一律不动。

## 五、手机端怎么用

1. 手机连上和电脑**同一个 Wi-Fi**
2. 浏览器打开 `http://<电脑局域网IP>:8766/?token=<TOKEN>`
   - 电脑 IP 查法：`Win+R` → 输入 `cmd` → 敲 `ipconfig` → 看「IPv4 地址」
3. 首次打开后，用浏览器的「添加到主屏幕」，之后就像 App 一样一点就开

## 六、iPhone 日历同步（订阅式）

**最快的方式**：网页「设置」→「iPhone 日历订阅」，卡片上有一张二维码，用 **iPhone 相机**扫一下就会跳到「订阅日历」确认页；卡片上的「复制订阅链接」也能把地址复制出来。卡片会按 **公网地址 → 局域网地址** 的顺序给出可用地址，优先用公网地址（手机用流量或任意 Wi-Fi 都能用）；想换一个地址就点地址下方的「局域网 …」按钮，二维码会跟着换。前提是**手机能访问那个地址**。卡片里的「测试地址」按钮会让**电脑本机**去读当前地址并报告读到几条事项：能读到说明地址和 token 都对；它读不到通常说明电脑自己走不到这个地址（例如没连 Tailscale、或防火墙拦了），可以在手机浏览器里直接打开同一个地址做最终确认。

手动路径：

1. 先确认电脑和 iPhone 在同一个网络；**不在同一网络**就用 Tailscale：
   - 电脑装好 Tailscale 并登录（在 Tailscale 托盘图标里能看到本机的 `100.x.x.x` 地址）
   - iPhone 也装 Tailscale、登录**同一个账号**
2. iPhone 打开：**设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历**
3. 服务器填：

   ```
   http://<你的电脑Tailscale地址>:8766/calendar.ics?token=<TOKEN>
   ```
   （同一 Wi-Fi 时也可以填 `http://<电脑局域网IP>:8766/calendar.ics?token=<TOKEN>`）

4. 保存，然后到「日历」App 里勾选这个日历
5. 刷新频率由 iOS 决定（通常几分钟到几小时一次）；想立刻刷新，下拉「日历」App

**同步规则**：待办在网页上标记完成后，iPhone 日历里那条会变成「已完成」；被忽略/过期的会变成「已取消」。

### 公网订阅与重订

公网订阅只有这一条地址：

```text
https://你的机器.example.ts.net/notice.ics?token=<TOKEN>
```

它由 Tailscale Funnel 转到本机 `127.0.0.1:8766/calendar.ics`。`?token=<TOKEN>` 不能省略；本机或同一局域网内仍使用上面的 `http://127.0.0.1:8766/...` 或 `http://<局域网IP>:8766/...` 地址。不要把公网地址改成别的端口或路径。

如果换过 token、日历内容长期不更新，或者旧订阅里看不到带具体时刻的新日程，按下面顺序重新订阅：

1. 在 iPhone「设置 → 日历 → 账户」里删除旧的已订阅日历。
2. 用 Safari 打开上面的公网地址，确认能拿到日历文本；如果打不开，先排查电脑服务和网络，不要直接重复添加订阅。
3. 回到网页「设置 → iPhone 日历订阅」，用 iPhone 相机扫描卡片上的二维码添加；也可以复制带 token 的订阅链接手动添加。
4. 在「日历」App 里勾选新订阅。

订阅日历不保证跟着「设置 → 日历 → 获取新数据 → 每 15 分钟」刷新；iOS 会按自己的计划获取订阅。需要马上看新任务时，在「日历」App 里手动下拉刷新。

如果日历里看不到带时刻的日程，先在电脑打开 `http://127.0.0.1:8766/api/health`；看到 `{"ok": true, "service": "qq-tasks"}` 才说明服务正在运行。服务日志在 `安装目录\logs\qq-live-digest.log`。旧版本导出的 ICS 缺少 `VTIMEZONE`，iOS 会丢掉这类带时刻的日程；当前版本已加入 `Asia/Shanghai` 的 `VTIMEZONE`，因此不要用旧订阅内容判断新版本是否正常，按上面的步骤重订。

## 七、想加群、退群怎么办

打开主页面，在「接入状态」那块：

- 上半部分是 QQ 登录状态和二维码（未登录时会自动刷新）
- 下半部分是群列表，**勾选 = 订阅，取消勾选 = 不再监控**
- 点保存后**立刻生效**，不用重启程序

> 白名单是「只有勾过的群才看」，没勾的群一律忽略——所以不用担心闲聊群污染。

## 八、出问题了

| 现象 | 原因 / 怎么办 |
|------|--------------|
| 网页打不开 | 程序没在跑。重新双击 `QQ-Notice-Hub.exe` |
| 接入向导显示「QQ 未连接」 | NapCat 掉线了。重新启动 NapCat（见 `docs/napcat-setup.md`），再回向导页扫码 |
| 二维码是旧的 / 扫了没反应 | 二维码约 2 分钟刷新一次，等它自己换一张再扫 |
| 一直没有新待办 | ①群没勾上 ②群里确实没有新通知 ③电脑在休眠 |
| iPhone 日历不更新 | iOS 刷新慢是正常的；确认手机能打开那个 `.ics` 网址 |
| 提取结果很奇怪 | 大模型偶尔会错。网页上有「原文证据」，以原文为准 |
| 网页关了但软件还在跑 | 正常。软件常驻在右下角托盘图标里，点托盘「退出」才会真正关掉 |
| 托盘图标不见了 | 软件没在跑，或已被退出。重新双击 `QQ-Notice-Hub.exe` |
| 点「开始托管」卡住十几秒 | 正常，它在关你的电脑版 QQ。等它出结果；一直不出就点托盘「退出」再重开 |
| 电脑版 QQ 登不上，提示已登录 | NapCat 正占着这个号。点托盘「结束托管」把 QQ 换回来，或给机器人换个 QQ 小号 |
| 找不到 `QQ-Notice-Hub.exe` 了 | 从桌面快捷方式进；没有快捷方式就回解压出来的 `qq-live-digest\` 文件夹双击它（首次运行会自动建桌面快捷方式） |
| 收件箱一直是空的 | 顺序：先点「① 回溯聊天记录」把消息抓下来，再点「② 提取通知」判定。只点一个不会有结果 |
| 回溯只能到很早以前的一小段 | 正常。NapCat 本地缓存会被 QQ 清理，越早越可能没了；点「探测最早时间」能看到实际边界 |
| 扫了订阅二维码，iPhone 说验证失败 | 手机连不上那个地址，跟服务器无关。改用同一 Wi-Fi 的局域网地址，或按第六节用 Tailscale 地址；也可以先点卡片上的「测试地址」 |
| 二维码扫不出来 | 用 **iPhone 相机**直接扫（不要用微信扫一扫）；扫不到就用卡片上的「复制订阅链接」手动粘贴 |
| 想重启服务但不想退出软件 | 托盘图标右键 →「重启服务」 |

### 服务会不会自己死掉（看门狗）

新版 `QQ-Notice-Hub.exe` 会看护内层 `qq-live-digest.exe`：启动器每 2 秒检查一次服务；服务退出后按 5 秒、15 秒、45 秒退避重启。重启期间网页和公网日历可能短暂打不开，等它自动恢复即可。

实测：2026-10-08 20:28 强杀内层服务（PID 45464）后，7.4 秒自动重起（PID 54908），8766/8765 恢复监听，`/api/health` 返回 200，启动器自身 PID 不变。

如果反复重启或一直打不开，查看：

```text
安装目录\logs\launcher.log
```

日志里会有类似「服务退出：pid=… code=…」的记录；服务本身的运行日志仍在 `安装目录\logs\qq-live-digest.log`。

## 九、出货包怎么用（发给别人 / 换电脑）

1. 解压 `QQ-Notice-Hub.zip`
2. 进入 `qq-live-digest\` 文件夹
3. 双击 **`QQ-Notice-Hub.exe`**
   - 会自动生成 `.env`、启动服务、打开浏览器、在桌面建一个「notice-hub」快捷方式
   - 右下角出现托盘图标，软件就在后台跑着了
   - 首次启动会要几秒
4. 之后按第二节走一遍
5. 想关掉：**托盘图标 →「退出」**

> 包里的 `qq-live-digest.exe` 是主程序，不要单独双击它（要通过 `QQ-Notice-Hub.exe` 启动）。
> 数据存在同目录 `data\`，想备份就备份这个文件夹。
> 托盘不在了但进程还在（极少见）：任务管理器里结束 `QQ-Notice-Hub.exe` 即可。

### 升级/更新

1. 下载新的 `QQ-Notice-Hub.zip`。
2. 先通过托盘菜单「退出」关闭 `QQ-Notice-Hub.exe`。
3. 把新包解压并覆盖到原安装目录（例如 `安装目录`）。
4. 覆盖时保留原目录里的 `.env`、`data\` 和 `logs\`，不要删除或改名。
5. 重新双击 `QQ-Notice-Hub.exe`，等待网页打开。

只要 `.env` 里的 `QQ_DIGEST_WEB_TOKEN` 没变，手机网页和 iPhone 日历订阅地址里的 token 就没变，不需要重新订阅；如果 token 改过，必须按第六节删除旧订阅并重新添加。

## 十、用哪个大模型

| 后端 | 说明 |
|------|------|
| **云 API（机器上没有大模型就用这个）** | 在 `.env` 里填 `QQ_DIGEST_LLM_ENDPOINT=` 和 `QQ_DIGEST_LLM_API_KEY=`，任意 OpenAI 兼容服务都行（DeepSeek、硅基流动、DashScope…）。免费层与低价选项见 [接入 API 指南](接API.md) |
| `auto` | **默认**。先试 CodeBuddy/WorkBuddy CLI（消耗你的账号额度），没装 CLI 或调用失败会自动回退本机 Ollama |
| `ollama` | 只用本机 Ollama 模型，免费、不出网 |
| `codebuddy` | 只用 CodeBuddy，失败就报错 |

改 `.env` 里的 `QQ_DIGEST_LLM_BACKEND=` / `QQ_DIGEST_LLM_ENDPOINT=`，然后重启程序即可。

**关于读图**：群里的图片要变成文字，得端点本身提供视觉模型。默认的 DashScope 端点自带（`qwen3-vl-plus`）；换成 DeepSeek、本机 Ollama 之类的端点后，图片会**只记录不识别**——不报错、不白花 token，日志提示一次。要重新读图，就在 `.env` 里显式写出该端点支持的视觉模型：

```ini
QQ_DIGEST_VL_MODEL=该端点支持的视觉模型名
```

## 十一、「托管」：让 NapCat 和你的电脑版 QQ 共用一台电脑

### 为什么需要它

同一个 QQ 号**不能在两个电脑端同时在线**（腾讯服务端规则）。NapCat 本身就是一个电脑端 QQ，所以：

- NapCat 登着你的号 → 你自己的电脑版 QQ 就登不上（会提示「已登录」）
- 你想用电脑版 QQ → 就得先让 NapCat 下线，待办也就停止收集了

「托管」就是替你做这个切换：**开始托管 = 先关掉电脑版 QQ，再启动 NapCat；结束托管 = 停掉 NapCat，把电脑版 QQ 开回来。**

notice-hub 启动的 NapCat 始终使用**独立资料目录**，所以它不会读到、也不会改动你本来的 QQ 数据；「托管」只关进程、再开进程，**绝不动你的 QQ 文件**。

### 怎么用

三个入口，效果一样：

1. **网页右上角**（推荐，随手就能点）：顶栏的「开始托管 / 结束托管」按钮，旁边的状态胶囊会写明现在是「未托管 / 引擎已启动，未登录 / 已登录，未开启托管 / 托管中」，点胶囊可以重新展开「开始使用」引导。
2. **右下角托盘图标**（软件启动后就在那里）：右键 →「开始托管」/「结束托管」/「重启服务」/「打开控制台」/「退出（结束托管并关闭）」。
3. **网页「设置」分区**：四个勾选项 + 托管状态 + 「开始托管」/「结束托管」按钮。

第一次用不知道从哪下手，就看**页面顶部那条「开始使用」引导**：它把「① 启动引擎 → ② 扫码登录 → ③ 选择订阅群 → ④ 订阅日历」四步按你当前的真实进度列出来（已完成的打勾），每一步右边都有按钮直接带你过去。四步都完成后引导自动收起；不想看就点「先不看」。

点「开始托管」后可能会**停顿十几秒**（关 QQ 需要时间），按钮会变灰并提示进度，这是正常的。

### 设置里的四个勾选项

| 勾选项 | 默认 | 作用 |
|--------|------|------|
| 自动退出电脑版 QQ | 开 | 开始托管时，自动关掉你的电脑版 QQ（取消勾选则只启动 NapCat，不碰你的 QQ） |
| 托管结束后恢复电脑版 QQ | 开 | 结束托管时，自动把你的电脑版 QQ 开回来 |
| 启动时自动开始托管 | 关 | 软件一启动就自动进入托管 |
| 开机自动启动 notice-hub | 关 | 开机自动运行（只写当前用户的开机启动项，**不需要管理员**） |

改完立刻写回同目录的 `.env`，不需要手动编辑文件。

### 设置里的「消息推送」

「截止提醒」要发得出去，至少得配一个推送通道。设置标签页里的**消息推送**填好点「保存推送设置」，会写回同目录 `.env` 并立刻生效（不用重启）：

| 通道 | 填什么 |
|------|--------|
| WxPusher | App Token + UID（或 Topic ID） |
| Server 酱 | SendKey |
| PushPlus | token |
| Webhook | 你自己的 POST 地址（`http` / `https` 开头） |

- 输入框留空 = 这一项不动；页面只回显尾 4 位掩码，永远不显示密钥明文。要全清点「清除全部推送设置」。
- 一个通道都没配时，右栏「服务自检」里的**消息推送**会标黄并给出「去设置」按钮，日志也只在状态变化时提醒一次（不再每 20 秒刷一行）。
- iPhone 日历订阅不依赖推送通道，它由 iOS 按自己的节奏刷新。

### 三种搭配，挑一个

| 情况 | 怎么做 |
|------|--------|
| 你的号平时主要用手机 QQ | NapCat 用你的号挂机，电脑上想用时点一下「结束托管」 |
| 想随时用电脑版 QQ | **申请一个 QQ 小号给机器人**（推荐），NapCat 登小号，你的号随便用，互不影响 |
| 只有一台电脑、又不想装第二个 QQ | 只能二选一，用托盘按钮手动切换 |

### 退出软件

**点托盘图标 →「退出（结束托管并关闭）」**（或在网页设置里先「结束托管」）。直接关浏览器标签页不会关掉软件，它还在后台跑。

## 十二、开机自启与看门狗

在管理员 PowerShell 中，从项目目录执行注册脚本（默认就是脚本所在目录，也就是解压 zip 后的文件夹；路径含空格时请用引号）。脚本会自动判断启动方式：解压出来的安装目录用同目录的 `QQ-Notice-Hub.exe`（自带看门狗），源码目录用 `run.ps1`。先空跑看一眼，不写任何东西：

```powershell
.\install-task.ps1 -InstallDir '安装目录' -WhatIf
```

确认输出的 `Execute`/`Arguments` 是你要的，再去掉 `-WhatIf` 真正注册（`-NapCatExecutable` 默认取安装目录下的 `NapCat.Shell.exe`，装在别处才需要显式指定）：

```powershell
.\install-task.ps1 -InstallDir '安装目录' -NapCatExecutable 'C:\Program Files\NapCat\NapCat.Shell.exe'
```

脚本幂等地创建三个任务：`NapCat-QQ`、`QQ-Live-Digest`、`NapCat-QQ-Watchdog`。卸载命令：

```powershell
.\uninstall-task.ps1
```

验证命令与预期输出：

```powershell
Get-ScheduledTask -TaskName 'QQ-Live-Digest'
# State 应为 Ready 或 Running
Get-ScheduledTask -TaskName 'NapCat-QQ','QQ-Live-Digest','NapCat-QQ-Watchdog' | Select-Object TaskName,State
```

看门狗任务会在服务任务不处于 Running 时启动 `QQ-Live-Digest`。需要定期清理旧备份时先预览：

```powershell
.\tools\cleanup-install.ps1
```

确认清单后再执行 `tools/cleanup-install.ps1 -Apply`；默认是 dry-run，`-WhatIf` 可显式保持预览模式。
