# 群务台 · 操作说明

比赛演示版，独立数据、独立端口，不碰装好的那一份。

## 一、需要什么

- Windows 10 或 11，装了 Python 3.11 以上（解压包里 `python.exe` 在 PATH 里即可）。
- 模型三选一，按你手边有什么：
  - **云端接口**（推荐）：把一把 OpenAI 兼容接口的钥匙写成一行放进 `demo\llm.key`。实测一句 2.4~3.2 秒，多调一轮工具的那句 11.9 秒。
  - **本机 Ollama**：没有钥匙时用它，先双击桌面「Ollama 本地模型」。一句 11~17 秒，第一句要等它把模型装进显存，约一分钟。
  - **都没有**：对话退回固定说法并当场说明原因，行程、地图、待办都不受影响。

## 二、三步跑起来

1. 解压整个压缩包，双击 `demo\启动演示.cmd`。
2. 脚本会写好一份演示数据（5 件待办、3 节课、1 条常做的事），然后自己打开浏览器：`http://127.0.0.1:8899/?token=demo&demo=1&nowiz=1`。
3. 想关掉：关掉那个黑色命令行窗口即可，数据留在 `demo\data` 里，下次打开还在。

`demo\llm.key` 不进压缩包，也不进仓库：发出去的是壳，钥匙留在自己机器上。想确认走的是哪条路，看启动窗口那行「模型：…」。

## 三、界面上有什么

- 顶上「今天几趟」：几件、几趟、走路合计。下面左边是校园等距地图，右边是今天要出门的几趟，每站带到达时间、楼名房间、留多久、为什么顺路。
- 地图下面是待办的概览卡：每张卡自带「完成 / 忽略 / 置顶」。再往下是「详情」页签，放已过期、已完成和月历。
- 最下面那条是对话输入条。点它，地图收成顶上一条窄带、行程让位给对话；点别处回来还是那张图。
- 「设置」里可以贴课表（一节课一行，写成「周一 08:00-09:40 高等数学 立德楼302」），也可以点「课表」→「选课表截图」让模型读一张教务截图（只出草稿，核对后点保存），还可以管「常做的事」。

## 四、能对它说什么

| 想做的事 | 可以这么说 |
| --- | --- |
| 查 | 我今天还有哪些事没办 |
| 提 | 周四下午三点去基础实验楼 B203 交物理实验报告 |
| 改 | 把取生活用品那件事改到明天 |
| 带地点 | 帮我记一件：去立行楼交班会材料 |

说完，回复下面就是「它做了什么」，默认摊开：读了几件待办、今天还有几节课、这一跳的打算、调了哪个工具、参数和结果。参数里的时间是「11 月 19 日 15:00」这种人话。

## 五、手机上用

1. 手机和电脑连同一个 Wi-Fi。
2. 手机浏览器打开 `http://<电脑的局域网 IP>:8899/?token=demo&demo=1&nowiz=1`。
3. 浏览器菜单里选「添加到主屏幕」，之后从桌面图标进，全屏无地址栏。
4. 没网或者电脑上那个窗口被关了，页面底下会浮一条说明，带「重试」。这一条是告诉你：屏幕上看到的是上次打开时留下的内容。

## 六、常见问题

- **对话回的是「模型这会儿没连上，先用固定说法回你」**：`demo\llm.key` 没写或写错；没钥匙就用本机 Ollama，先双击桌面「Ollama 本地模型」。行程和地图不受影响。
- **端口 8899 被占**：改 `demo\启动演示.cmd` 里 `NOTICEHUB_WEB_PORT` 那一行，换成别的端口。
- **数据在哪**：`demo\data` 目录。想从头再看一遍，关掉窗口，删掉这个目录，再双击启动脚本。
- **想换成自己学校**：数据目录里的 `campus_poi.json` 换成自己学校的楼（名称、别名、相对坐标、营业时间），覆盖内置值就生效，不用改代码。
