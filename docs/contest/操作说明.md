# 群务台 · 操作说明

比赛演示版，独立数据、独立端口，不碰装好的那一份。

## 一、需要什么

- Windows 10 或 11。离线包（`群务台-演示包.zip`）不用装任何东西；源码包要 Python 3.11 以上（`python.exe` 在 PATH 里即可）。
- 模型：包里**不带**钥匙。没有钥匙时输入框只回一句「模型这会儿没连上」，不会凭空编答案；待办、行程、地图照常，因为它们不靠模型算。想要真对话：把一把 OpenAI 兼容接口的钥匙写成一行，放进启动器同目录的 `llm.key`（源码版在 `demo\llm.key`，安装版在包根目录），就走云端接口，实测一句 2.4~3.2 秒，多调一轮工具的那句 11.9 秒。
- 没有钥匙时后端是 `auto`，对话退回固定说法并当场说明原因，不会去连本机 Ollama；行程、地图、待办都不受影响。想改用本机 Ollama，自己把 `NOTICEHUB_LLM_BACKEND` 设成 `ollama`。

## 二、三步跑起来

1. 解压整个压缩包，双击 `启动演示.cmd`（离线包就在根目录，源码包在 `demo\` 下）。
2. 脚本会写好一份演示数据（5 件待办、3 节课、1 条常做的事），然后自己打开浏览器：`http://127.0.0.1:8899/?token=demo&demo=1&nowiz=1`。
3. 想关掉：关掉那个黑色命令行窗口即可，数据留在 `demo\data` 里，下次打开还在。

`llm.key` 不进仓库（`.gitignore` 挡着），演示包里也没有——钥匙是你自己塞进去的，别指望包自带。想确认走的是哪条路，看启动窗口那行「模型：…」。接口地址和模型可以用 `NOTICEHUB_LLM_ENDPOINT`、`NOTICEHUB_LLM_MODEL` 改。

## 三、界面上有什么

- 顶上「今天几趟」：几件、几趟、走路合计。下面左边是校园等距地图，右边是今天要出门的几趟，每站带到达时间、楼名房间、留多久、为什么顺路。
- 地图下面是待办的概览卡：每张卡自带「完成 / 忽略 / 置顶」。再往下是「详情」页签，放已过期、已完成和月历。
- 最下面那条是对话输入条。点它，地图收成顶上一条窄带、行程让位给对话；点别处回来还是那张图。
- 「设置」里可以贴课表（一节课一行，写成「周一 08:00-09:40 高等数学 立德楼302」），也可以点「课表」→「选课表截图」让模型读一张教务截图（只出草稿，核对后点保存），还可以管「常做的事」。

## 四、能对它说什么

| 想做的事 | 可以这么说 |
| --- | --- |
| 查 | 我今天还有哪些事没办 |
| 提 | 周四下午三点去武进楼 B203 交物理实验报告 |
| 改 | 把取生活用品那件事改到明天 |
| 带地点 | 帮我记一件：去立行楼交班会材料 |

说完，回复下面就是「它做了什么」，默认摊开：读了几件待办、今天还有几节课、这一跳的打算、调了哪个工具、参数和结果。参数里的时间是「11 月 19 日 15:00」这种人话。

## 五、手机上用

1. 手机和电脑连同一个 Wi-Fi。
2. 手机浏览器打开 `http://<电脑的局域网 IP>:8899/?token=demo&demo=1&nowiz=1`。
3. 浏览器菜单里选「添加到主屏幕」，桌面上就有一个图标。iPhone 从图标进是全屏无地址栏（`apple-mobile-web-app-capable`）；安卓 Chrome 在局域网 http 下只给一个快捷方式，地址栏还在。
4. 断网、或者把电脑上那个窗口关掉，手机就打不开了——数据都在电脑上，页面上没有本地副本。局域网走的是 `http`，浏览器不把它当安全来源，`navigator.serviceWorker` 压根不存在（实测 `isSecureContext: false`），所以没有缓存可读。演示时别演「断网还能看」，那是没有的事。

## 六、常见问题

- **对话回的是「模型这会儿没连上，先用固定说法回你」**：启动器同目录没有 `llm.key`，或者钥匙写错了。把有效钥匙写进 `llm.key` 再启动；钥匙错时回复里只说模型没连上，上游到底报了什么看 `logs/` 下的日志。行程和地图不受影响。
- **手机上想要「装成 App」**：安卓可以用安装版 APK（`android\app\build\outputs\apk\release\app-release.apk`），装完第一次打开会让你填电脑的地址（`http://电脑IP:8899`）。它是个客户端外壳，连的还是电脑上那份服务，电脑关了就一起断。iPhone 不需要装东西，「添加到主屏幕」就有一个全屏图标。
- **端口 8899 被占**：改 `demo\启动演示.cmd` 里 `NOTICEHUB_WEB_PORT` 那一行，换成别的端口。
- **数据在哪**：`demo\data` 目录。想从头再看一遍，关掉窗口，删掉这个目录，再双击启动脚本。
- **想换成自己学校**：数据目录里的 `campus_poi.json` 换成自己学校的楼（名称、别名、相对坐标、营业时间），覆盖内置值就生效，不用改代码。
- **楼层数和位置不对**：同一份 `campus_poi.json` 里只写要改的那几项，例如 `{"id": "library", "floors": 7}` 改层数，`{"id": "gym", "dx": 10, "dy": 20}` 把整栋楼往东北挪一点（米，向东、向北为正；API 里的 y 仍朝南，方向由程序换算）。没写的字段保留内置值，写错的楼层或偏移会被忽略，不会把地图整崩。
