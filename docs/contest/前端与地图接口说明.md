# 前端与地图接口说明（给接手的 agent）

这份文档只讲「页面 ↔ 后端」和「地图怎么画」两件事，用来接着改前端与地图功能。所有字段都以代码为准，这里给的是路径与行号，改之前先去看那几行。

## 1. 数据怎么流

```
page.html（页面骨架 + 排版，CSS 全在里面）
  └─ js/trip.js      今日行程：取 /api/agent/plan，决定画地图还是画行程条，再往下画
       ├─ js/map3d.js   有 WebGL 就交给它：楼是真体块、带光、可转视角
       └─ js/campus-osm.js  底图轮廓（校园路网、水面、楼块多边形）与校准参数
  └─ js/notice.js    最近推送、收件箱
  └─ js/settings.js  设置页
  └─ js/announce.js  公告与铃
  └─ js/guide.js     引导浮层（journey / onboarding）
  └─ js/pair.js      配对、二维码
```

智能体对话（读/想/调三步过程、行程、改待办）走 `/api/agent/chat`，答案与调用链一起回来，页面把 `trace` 一条条铺在对话记录区。

## 2. 接口清单

| 方法 | 路径 | 请求 | 响应关键字段 | 代码位置 |
| --- | --- | --- | --- | --- |
| GET | `/api/agent/plan` | 无 | `ok`、`plan`（见下）、`plan.pois[]`、`plan.trips[].line` | `noticehub/webapp.py:4777` → `application/agent_plan.py:78 today_plan` |
| POST | `/api/agent/chat` | `{"text": "...", "session": "..."}` | `ok`、`say`、`trace[]`、`changed` | `application/agent_chat.py:109 chat_turn`，响应装配见 `:249` |
| GET | `/api/agent/brief` | 无 | 今况简报（浮球与首屏共用） | `application/agent_brief.py:9` |
| GET/POST | `/api/agent/schedule` | 课表文本 / 结构化 | `ok`、`lessons`、`rejected` | `agent_plan.py:32-34`、`:155 parse_schedule_text` |
| GET/POST | `/api/agent/routines` | 常做的事 | `ok`、`routines[]` | `agent_plan.py:375-390` |
| POST | `/api/agent/plan`（`action=order`） | `{"date": "YYYY-MM-DD", "order": [标题...], "groups": [[标题...]]}` | `ok`、`order`、`groups` | `agent_plan.py:431 save_plan_order` |
| GET/POST | `/api/agent/map/config` | 地图厂商钥匙 | 各家有没有配 | `agent_plan.py:638` |
| GET/POST | `/api/agent/campus/poi` | 自定义地点 `{name, x, y, kind}` | `ok`、`poi`、`count` | `agent_plan.py:725-741` |

`/api/agent/plan` 的 `plan` 形状（`agent_plan.py:78-130`）：

- `pois[]`：`{id, name, x, y, zone, kind, floors, src}`。坐标是「平面图坐标」（不是经纬度），`src` 取值 `osm / osm-footprint / estimated / unknown`，页面把 `estimated` 画虚线。
- `trips[]`：`{zone, from_place, stops: [{place_id, seq, stay_min, arrive, place}], line: [[x, y], ...]}`。`line` 是后端 `campus_roads.road_line()` 算出来的绕楼折线（`agent_plan.py:133 _attach_road_lines`），页面「绕楼」档用它，「直线」档不用。
- `rest[]`：排不进去的事，带原因；页面上折叠成「没说地点，先放着」。
- `here`：用户标的「我在…」，`{id, name, at}`；没标就是 `null`，默认起点退回课表最后一节课那栋楼。
- `counts`、`warnings[]`、`lesson_count`、`poi_count`、`path`。

## 3. 地图坐标与校准

- 地点表：`noticehub/web_static/js/campus-geo.json`（27 个内置 POI），字段 `x/y/zone/kind/floors/src`。用户自定义地点存在数据目录的 POI 文件里，`/api/agent/campus/poi` 写入，页面不直接改 JSON。
- 平面图坐标 → 底图快照坐标：`planToSnapshot = {a: 1.006566, b: 0.157187, tx: 58.369, ty: 177.285}`。
- 底图快照 → 屏幕：`calibration.osmToPoi = {sx: 0.8065, bx: 170.4, sy: 1.0382, by: -327.5}`，在 `campus-osm.js` 里。
- 比例：`metersPerPixel = 0.9`。后端算距离用平面单位「1 单位 = 1 米」（`application/trips.py:50 math.hypot`），**别把 metersPerPixel 混进后端**。
- 底图多边形只有 6 栋带名字，其余靠 `campus-geo.json` 的楼名；`src: estimated` 的位置是手摆的（博雅居 `[281,572]`、白云楼 `[480,832]`、马士楼 `[638,843]`、汤湖楼 `[593,926]`、立德楼 `[358,1101]`、立功楼 `[661,1146]`），页面上用虚线标出来，别假装是实测。
- 不接外部地图厂商：OSM/高德/百度三档只在用户配了钥匙时出现，没钥匙就自动收起来。

## 4. 画图的三个模块

`js/trip.js`（8.4 万字节，主力）

- `drawMap(plan)` 是总入口（`:84`）。先量 `#trip-map` 的盒子：
  - 宽度 < 40 → 返回（切页签、收合中，等 `ResizeObserver` 叫醒，见 `bot` 段 `:1784`）。
  - 高度 < 200 → 撤掉 3D 画布、改画横向行程条 `drawStrip()`（`:70`、`:116`）：对话态就是这么来的。
  - 否则交给 `nhMap3d.draw()`；没有 WebGL 就走同文件里的 SVG 兜底。
- 楼名绘制顺序在 `:214` 一带，`NAMED` 名单 `:63`（`ligong/lide/lixing/tuwen/library/boyaju/canteen1/gym`），名单里的 id 必须真实存在于 `campus-geo.json`。

`js/map3d.js`（3.8 万字节）

- `:348`：`compact = W < 420 && Hh < 300`。
- `:575`：`pad` 是标签安全区，现在一律 `{l:0, r:0, t:0, b:8}`。**别再给顶部留位置**：控件已经从画布搬到画布上方的 `.map-modes` 工具栏，留 78 像素会把北侧楼名顶出画框。
- 标签不再有「窄屏白名单」：挤不挤交给 `place()` 逐格碰撞，上限 `namedShown >= 12`（`:504`）。

`page.html`（排版）

- 宽屏（≥1100）两栏：`main` 网格，左列概览 + 待办列表，右栏地图 + 今天几趟（`page.html:2195-2247`）。
- 窄屏（≤720）单栏按顺序排：轮转待办卡 → 今天几趟（`order:2`）→ 待办板（`order:3`）→ 概览（`order:4`）→ 对话（`order:5`）。
- 待办板列表形态规则在 `:2098-2172`；切到别的页签时 `body[data-tab]:not([data-tab=tasks]) .task-board-block{display:none}`。

## 5. 不许回退的行为（每条都有用例守着）

| 行为 | 用例（`tests/test_ui_browser.py`） |
| --- | --- |
| 390 与 1280 上地图都必须是 3D 画布，不许退成行程条 | `test_agent_route_lands_on_the_map`、`test_desktop_rail_map_keeps_the_3d_layer` |
| 楼上该有的名字要画出来（按名字断言，不是数个数） | `test_map_frames_every_building_it_draws`、`test_map_is_drawn_north_up_and_east_right` |
| 对话态把地图压扁后必须出现行程条 | `test_trip_order_follows_walk_not_input_order` |
| 点别处地图要回满高（含 260ms 过渡落定后再量） | `test_clicking_elsewhere_puts_the_map_back` |
| 待办板不许横向溢出，日期组头单行、不压邻道 | `test_timeline_board_hints_sideways_overflow`、`test_timeline_board_keeps_date_labels_and_sideways_position` |
| 卡片悬停位移不被组头吃掉，按钮点得中 | `test_timeline_board_cards_are_equal_and_hover_is_hittable` |
| 切页签、换字号、重画都不丢位置与列宽 | `test_tab_switch_and_settings_rerender_keep_scroll_and_width` |
| 对话记录滚到底最后一行不被输入栏压住 | `test_agent_trace_scrolls_with_long_places`（探针 `tests/ui_trace_probe.js`） |

改地图或排版之后，这些用例是契约：**不许放宽断言、删用例或 skip**，产品逻辑去迁就它们。
