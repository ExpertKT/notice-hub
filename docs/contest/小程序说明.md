# 微信小程序客户端说明

工程位于 `miniprogram/`，导入、连接配置和真机预览条件见 `../../miniprogram/README.md`。

## 本批交付

- 三个原生页面：待办列表、对话、canvas 等轴测楼层图；连接设置单独成页。
- `baseUrl` 与 `token` 无预填值，通过 storage 保存；四个已有接口均使用 `X-Token`。
- 网络失败、401/403、其它 4xx、5xx、响应格式错误分别有提示和下一步入口。请求可停止，离页取消等待，旧响应不覆盖新状态。
- 对话发送 `{session_id,text}`，成功采用返回的会话 ID；失败保留输入，提醒先查待办再重发。
- 地图是三座虚构建筑的固定示例，不接真实地图接口，不声称真实位置或楼层数据。

## 动线与视觉取舍

首次进入先填连接信息，保存后回待办。待办、对话、地图为高频底部入口，连接设置放在每页右上角；没连服务也能看地图。列表以文字和分组为主，地图是主要图形区；用深蓝标选择中的楼层，文字同时标注当前建筑和层数。系统中文字体，正文 `32rpx`，按钮最小高度 `88rpx`。
