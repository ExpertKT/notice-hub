## 二、演示视频（MP4，3–5 分钟）

- 分镜脚本以 `docs/contest/演示视频分镜.md` 为准（0:00–4:10，逐段画面 + 口播），落在附件1 的 3—5 分钟区间中段；`docs/contest/演示脚本.md` 是三分钟压缩版，备用。两版不要混着录
- 录制前先按下面「三」把演示版跑起来，在输入框说一句话，确认真答了（包里带钥匙，一句三到五秒）。只剩固定说法就是 key 过期了，换一把再录，视频里那句答不上话很难看
- 录完检查：画面能看清输入的那句话与「它做了什么」三步；失败场景那一段要拍到红字提示，不是靠旁白

- 程序：`demo/启动演示.cmd`（双击 → 造演示数据 → 开浏览器到 `http://127.0.0.1:8899/?token=demo&demo=1&nowiz=1`）
