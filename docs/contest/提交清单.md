# 初赛提交清单（对照附件1、附件2）

按附件1《作品提交要求》，初赛交三样东西。这一页把每一样对应到本仓库里的文件，交之前照着核对一遍。

## 一、项目计划书（PDF）

- 文件：`docs/contest/群务台项目计划书.pdf`（渲染源文件是同目录的 `群务台项目计划书.html`）
- 对外提交时按附件1 的命名规范改名：`群务台项目计划书（智能体创新大赛）.pdf`
- 附件1 要求的三章都在计划书里：
  - 项目概述（应用背景、解决问题、项目目的、创新点）→ 第一章，1.4 之后「创新落在五个动作上」、1.5 输入条件与预期输出
  - 技术方案（总体架构、功能概述、模型与工具、关键技术）→ 第二章，2.3 里写明「模型管到哪为止」，区分了自主实现与第三方能力
  - 项目计划（可行性分析、团队分工、当前完成情况）→ 第三章，3.5 是实测记录（五句真实请求的耗时与结果）
- 第三方与开源来源在 4.1 表里逐项标注（附件1 扣分项：漏标 5–15 分）

## 二、演示视频（MP4，3–5 分钟）

- 分镜脚本：`docs/contest/演示视频分镜.md`（0:00–4:10，含失败场景与手机端）
- 录制前先按下面「三」把演示版跑起来，并确认 Ollama 已开（否则对话会退成固定说法，视频里难看）
- 录完检查：画面能看清输入的那句话与「它做了什么」三步；失败场景那一段要拍到红字提示，不是靠旁白

## 三、可运行原型 + 运行方式

- 程序：`demo/启动演示.cmd`（双击 → 造演示数据 → 开浏览器到 `http://127.0.0.1:8899/?token=demo&demo=1&nowiz=1`）
- 操作说明：`docs/contest/操作说明.md`（三步启动、界面导览、四句示例、手机加到主屏幕、常见问题）
- 形态效果图：`docs/contest/形态效果图.html`（单文件、不连网，三个画面：桌面待办 / 对话盖上来 / 手机 390；答辩和视频取画面用）
- 环境：Python 3.11+；不需要装数据库或前端工具链；本机模型用 Ollama（不开也能跑，对话会说明已降级）
