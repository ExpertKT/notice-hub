# 演示脚本 · 3 分钟

替代 `docs/contest/演示视频分镜.md`（3–5 分钟旧版）。这一版按附件1 的 3 分钟上限压：只演四件事——排好的行程、它怎么调工具、手机端、认不出地点时的样子。

素材：`docs/contest/形态效果图.html` 三屏（桌面 / 对话 / 手机，示意稿）、真实实例 `http://127.0.0.1:8899/?token=demo&demo=1&nowiz=1`、`demo/启动演示.cmd` 的 seed 数据。

## 录制前 10 分钟

1. 起 Ollama（桌面「Ollama 本地模型」），确认模型在：`curl http://127.0.0.1:11434/v1/models`。没有就别录对话段，改用「模型没连上，先用本地规则筛选」的截图——不要对着空回复硬录。
2. 双击 `demo/启动演示.cmd`。它会写 seed（5 件待办、3 节课、1 条常做的事）并在 8899 开一份独立实例，不碰 8766 那份。
3. 浏览器窗口 1280×800，缩放 100%，关掉系统通知与微信/QQ 弹窗。录屏工具只录窗口，别录整屏。
4. 打开 `http://127.0.0.1:8899/?token=demo&demo=1&nowiz=1`，先在输入条里把对话清一次，确保录到的第一轮是干净的。
5. 手机上把同一地址加到主屏幕，提前装好，录的时候直接点图标。

灯光、口播、字幕这些不用多说。只有一条：鼠标动线要慢，别在 3D 地图上乱甩。

## 每句话对应哪个工具调用

录屏时 trace 里出现的行，与口播要对得上，别让画面和话打架。

| 口播 / 输入 | 屏幕上的 trace | 代码里怎么走 |
| --- | --- | --- |
| 「把实验报告改到明天下午」 | 读 → 想 → 调「改期（第几件 N，截止 11 月 17 日 15:00）：」加工具回的那句 | `reschedule`；「明天下午」由 `_coerce_deadline` 换成 `2026-11-17T15:00`（下午默认 15:00，没钟点给 23:59） |
| 「删掉第 2 件」 | 调「改状态（第几件 2，动作 删除）：」加一句要确认的话 | `act` + `action=delete`；首次只记 pending |
| 「确认」 | 调「改状态（第几件 2，动作 删除，确认 已经确认过）：」加结果 | `act` + `confirm=true` 才真删 |
| 「明天去东门取快递」 | 行程里多一条「没认出地点」，或回复里说明不认识 | `match_place` 返回 None，`_collect_candidates` 放进 unscheduled |

工具中文名就是页面上显示的那套：新建、改标题、改期、改状态、置顶、标紧急、清空已完成。参数也翻成中文（「第几件」「截止」「动作」），不会把 `2026-11-17T15:00` 这种原文甩在屏幕上。

## 哪些数字是示意，哪些是真跑

形态稿和演示实例现在用同一套真校区坐标（17 栋），差别只在形态稿是设计稿、演示是真页面，所以两边的数各算各的。录屏时念演示里的数，形态稿那列的用处是对照，不是台词。

| 形态稿（立德楼→图书馆→一食堂→学生公寓A，真坐标） | 真实实例（2026-11-16 周一实跑，demo seed） |
| --- | --- |
| 2 趟 · 走路 10.3 分钟 | 2 趟 · 走路 20 分钟 |
| 第 1 趟 534.8 米，走路 7.1 分钟（13:50 出发，14:02 到一食堂） | 1385 米，两趟合计 |
| 4 个停靠点（立德楼 / 图书馆 / 一食堂 / 学生公寓A） | 6 个停靠点（立功楼、博雅居、行政楼、图文信息楼、一食堂、菜鸟驿站） |
| 工具名 schedule / plan_route / deadline_check / poi_near | 真实工具是 reschedule / act / create 等七个 |

效果图的三屏都用上了：桌面在 0:00，对话在 0:08，手机在 2:20，各切到真实页面前一秒。口播不要说效果图里的数字。若评委问，答「那是形态稿，实跑数字在演示里」。

## 不要放进视频的东西

- 不要念「离线也能用」：service worker 只缓存外壳，`/api/` 不缓存，断网只能打开空壳。
- 不要说「有小程序」：没有。
- 不要展示 8766 那份正在用的实例、真实 QQ 号、群号、token 明文。
- 不要剪掉失败那一段。附件2 里「效果与可靠性」扣分点就在「有没有说明失败情形」。
