# 群务台 · 演示要点

这份是评委自己上手时的路线，每一步该看到什么写在后面（录视频按 `演示视频分镜.md` 走，三分钟压缩版是 `演示脚本.md`）。全部基于 `demo/启动演示.cmd` 的 seed 数据，双击就能复现。

## 一、它是什么，先看 30 秒

双击 `demo/启动演示.cmd`。它在 8899 起一份独立实例，数据写在 `demo/data`，不碰电脑上 8766 的那份已经装好的。浏览器打开 `http://127.0.0.1:8899/?token=demo&demo=1&nowiz=1`。

首页三块：

- **待办台**：5 件待办，地点写在标题里（「交班会材料 立行楼302」）。其中两件带截止时间：立行楼那件今天 20:00，武进楼那份实验报告明天 18:00——所以今天排不进去。真实使用时由 NapCat 把群消息 POST 到 8765，receiver 落库、过滤、攒批、交给 summarizer 摘要；演示包里这 5 件是 `demo/seed.py` 直接写进去的，省掉了收消息那段。
- **今天几趟**：2 趟、5 站、1044 米，两趟走路合计 16 分钟（每趟分段取整；1044÷70≈14.9 分钟）。第 1 趟 15:40 从立德楼下课出发，3 站、586 米（立德楼 512 找同学拿材料、立行楼 302 交班会材料、图书馆还书）；第 2 趟 16:30 生活区，2 站、458 米（第一餐厅吃饭、1 号楼取生活用品）。武进楼 B203 那份实验报告截止在明天 18:00，今天排不进去，单列在「排不进去」里并写明理由——这一栏不是漏排，演的时候顺口说明。两张卡上的分钟各自取整（9 加 7），抬头把两趟相加写 16。这些数由后端算，页面不自己编。
- **对话**：一个输入条，加一块默认摊开的「它做了什么」。

演示包里没有真 QQ 群。这点当场说清楚，比被问出来好。

## 二、智能体在哪一步做了决策（核心，2 分钟）

在输入条打这一句：

> 立德楼这边下课，把还书、交班会材料、交实验报告排一下，先看附近还有哪些没办。

「它做了什么」里会出现三行：读、想、调。指给评委看：

1. **读**：读了几件待办、今天几节课、最后一节几点在哪栋楼下课、刚才几轮对话。这段是系统从数据库和课表拼的，不是模型说的。
2. **想**：模型自己选工具。这一句它选 `poi_near`，参数 place=立德楼、radius_m=500。
3. **调**：工具返回「立德楼 500 米直线半径内 15 处地点、5 件未完待办」，页面印出立行楼 155.1 米、武进楼 270.9 米、图书馆 295.5 米，还书那件就在图书馆那栋楼里。

再打一句「按最近的顺序排」。它选 `plan_route`，返回立德楼 → 立行楼 → 武进楼 → 图书馆，155.1 + 413.6 + 43.1 = 611.8 米，步行约 8.7 分钟；用户说的顺序要走 1139.8 米，省 528.0 米。如果没有更顺的顺序，它照实说「和输入顺序一致，没有更顺的顺序」，不会硬凑一个数。

要指出的关键点：**里程和时间没有一个字是模型写的。** 两个工具都返回 `changed: false`，只能算、不能改待办；模型要报数字，只有工具返回值这一个来源。模型写的部分是「先找附近，再定顺序」这个选择本身，以及那句人话。

三条护栏，各点一次就够：

- 输入「删掉第 2 件」：它先反问，不直接删；回「确认」才动手。
- 输入一件已有的事但地点写错（比如「明天去东门取生活用品」）：它说认不出这个地点，不硬排。
- 断掉模型（演示包里没有 `llm.key`）：启动器把后端设成 `auto`，`chat_ready` 直接返回 False，对话里自报「没有模型，这句按本地规则办的」，不会去连本机 Ollama。还能演的两句：「今天怎么安排」真排一遍报出 2 趟、5 站、1044 米、头一趟 15:40 从立德楼出发走立行楼、图书馆；「立德楼附近有什么」报 15 处地点、5 件未完待办，再由近到远列三处米数（立行楼 155.1、武进楼 270.9、汤湖楼 293.1）。行程照常排得出来——排序和校验本来就不经过模型。

## 三、手机端怎么用（1 分钟）

手机和电脑连同一个局域网。Windows 上服务默认监听 `0.0.0.0`，手机浏览器打开 `http://<电脑局域网IP>:8899/?token=demo` 就能进（首次可能要点一下 Windows 防火墙的允许）。页面按 390 宽重排：底栏在下面，行程里的站只留楼名，地图单指上下滑滚页面、横向拖动转视角。手机上这一遍只看布局和手感。

装到桌面、断网离线这两件要有「安全上下文」才成立——https，或者浏览器认的本机地址（127.0.0.1 / localhost）。局域网 http 地址下浏览器不给装桌面的入口，service worker 也不注册，网一断页面就打不开。所以这两段回电脑上，用 `http://127.0.0.1:8899/` 演：

- **装到桌面**：页头右边出现「装到桌面」（装过就不再出现）。Chrome / Edge 点它直接弹安装窗，装完是一个没有地址栏的独立窗口；Safari 走弹窗里那段分享菜单。
- **断网**：开发者工具里把 Network 调成 Offline，页面底部浮出「没网了。这一页是上次打开时留下的，连上以后点「重试」才更新。」
- **服务关掉、网还在**：关掉演示窗口再刷新，页面从缓存外壳打开，浮出「连不上群务台的服务。它可能被关掉了：双击 QQ-Notice-Hub.exe，再回来点「重试」。」

两种都接一句「当前只读；保存、改待办和对话暂不可用」，发送、语音、保存课表这些按钮变灰。数据留在电脑上，手机只是外壳；断网能看上次的排法，看不到新数据——`/api/` 故意不缓存，旧数据装成新数据比白屏更糟。

### 演示环境的安全边界

冷装实测，演示实例监听的是 `0.0.0.0:8899`（`demo/启动演示.cmd` 不设 host），链接里带着 `token=demo`。也就是说，同一个局域网里知道这个地址的人都能直接打开它。手机要用局域网地址才连得上，所以绑定地址不动，这一条靠现场口径来挡：

- 只在自己家的、或者自己带的那个局域网里演。咖啡店、教室的公共 Wi-Fi 也算公共场合。
- 带 token 的链接不发群、不发同学、不贴文档。截图和投屏只露页面，不露地址栏。
- 演完关掉那个命令行窗口，8899 就不在监听了。

`token=demo` 是演示用的固定值，不是真钥匙。别拿它去套用户那份 8766 的实例，那边是另一把。

## 四、评委常问的四句

| 问题 | 怎么答 |
| --- | --- |
| 模型关了还能用吗？ | 能。排程、聚类、走路时间、截止校验都是本地计算，模型只负责把话转成 JSON 和挑工具。 |
| 距离准不准？ | 直线估算，坐标按校方平面图量取（0.9 米/像素），每栋拿同名地图点复核，残差 16–94 米；是示意图不是测绘。差二十米对走路没影响，但绕不绕路它算不出来。 |
| 换个学校要改多少？ | 27 处地点内置在 `noticehub/application/campus.py` 的 `DEFAULT_POIS`（楼名、别名、层数），坐标在 `noticehub/web_static/js/campus-geo.json`（从 OSM 换算）；数据目录里写一份 `campus_poi.json` 能改坐标、加别名、加新楼，内置的那几条删不掉、只能盖。换整所学校要连楼名和坐标一起给，代码不动。 |
| 有小程序吗？ | 有源码工程：`miniprogram/`，待办、对话、地图三个入口加一页连接设置，`checks/check.cjs` 是 node 探针，覆盖解析和错误分支。没在真机跑过——要换成自己的 AppID 导进微信开发者工具，正式访问还要 HTTPS 合法域名。手机端日常能用的是 PWA（添加到主屏幕）；安卓 APK 只有工程没打包，仓库里没有产物。 |
| 手机上怎么没有「装到桌面」按钮？ | 局域网 http 地址不算安全上下文，浏览器不给装。本机 127.0.0.1 或 https 下才有这个按钮，离线外壳也一样；iPhone 也能从分享菜单手动加。 |
| 小程序那份返回算云端证据吗？ | 不算。那次接的是固定本地端点，只证明同一套 `poi_near`、`plan_route` 在小程序侧能通，不证明云端模型或自主决策。 |

## 五、演示纪律

- 不说「离线也能用」。断网能打开页面、能看到上次的排法，写不进去——照实说这一句。
- 不在手机上演断网：局域网 http 下没注册 service worker，关掉网只会看到浏览器自己的错误页，那两段文案要在电脑的本机地址上出。
- 不展示 8766 那份正在用的实例、真实 QQ 号、群号、token 明文。
- 不念形态效果图里的数字。那是设计稿，实跑数字以演示页面为准。
- 失败那一段不要跳过。附件里「稳定性与校验」的分就在有没有把失败情形说清楚。
