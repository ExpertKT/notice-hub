# 群务台 · 演示视频分镜（3–5 分钟）

一条横屏（16:9）录屏，手机上另拍两段竖屏小窗贴进去。全程用演示版（`demo\启动演示.cmd`），不碰正式实例。

## 0:00–0:20 开场，先把问题摆出来

- 画面：十几个 QQ 群的消息列表快速上滑；切到相册里一堆截图；切到备忘录。
- 旁白：通知散在群里，截图存进相册，临出门前翻一遍靠记忆决定先去哪。结果是当天只办掉最近的两件，还有一件因为忘了驿站 20:00 关门白跑一趟。
- 字卡：群务台 —— 把散在群里的通知，排成今天走得完的几趟。

## 0:20–0:50 打开就是答案

- 画面：双击启动脚本 → 浏览器打开 → 镜头停在「今天几趟」。
- 要点：抬头写「5 件 · 2 趟 · 走路 16 分钟」；左边地图两趟用两条线画出，编号 1、2、3；右边两张行程卡，每站带到达时间与「留在原地，顺路先办」这种理由。武进楼那份实验报告截止在明天，落在「排不进去」里，演的时候顺口说明这一栏不是漏排。哪一段只能按直线画，图上会自己标「这一段没接上路网，按直线估的距离」——屏幕上出现了就顺手点一句「它不假装那儿有路」，没出现就别念这句。
- 旁白：不用点任何按钮，打开就是今天怎么走。

## 0:50–1:40 说话提一件事（核心）

- 操作：点底部输入条，地图收成窄带；输入「周四下午三点去武进楼 B203 交物理实验报告」，回车。
- 画面停在回复下面的「它做了什么」，逐条念：
  1. 读了 5 件待办、今天还有 3 节课（最后一节 15:40 下课）——录屏在傍晚就显示「今天的课都上完了」，按当时屏幕念
  2. 这一跳的打算
  3. 调 create，参数是标题和「11 月 19 日 15:00」
- 然后回到常态：待办池多出这一件，地图上多一个点，行程重排。
- 旁白：它自己决定调哪个能力，过程和结果都摆在明面上。

## 1:40–2:20 查与改

- 操作 A：「我今天还有哪些事没办」→ 它列出几件，过程只有一步读。
- 操作 B：「把取生活用品那件事改到明天」→ 认到那一件，调 reschedule，参数里的日期是人话。
- 旁白：同一句话里增、查、改都走这一条入口；模型只负责听懂，排序、校验、写库都是程序自己的活。

## 2:20–3:00 手机端

- 竖屏拍摄：浏览器菜单 →「添加到主屏幕」→ 从桌面图标进（全屏无地址栏）→ 说一句「帮我记一件：去立行楼交班会材料」→ 回复与过程照常。
- 弱网这一段拍「等」，不拍「断网」：电脑上把浏览器网络节流成 Slow 3G，手机上发一句「帮我记一件：去立行楼交班会材料」，把等待状态和回来后的回复都留在画面里。**断网不要演**——局域网 http 下浏览器不给 service worker，关掉电脑窗口手机就是打不开，演了等于自己拆台。
- 旁白：手机上就是同一个界面，加个图标就能全屏用；数据全在电脑上，手机只是个门。

## 3:00–3:43 地图这套不是写死的

- 画面：设置 →「校园地图」。先把「图书馆」的显示名改成「图书馆（旧馆）」，再把「快递自提点」摆到地图上，删掉一条自己加的临时点；切到地点清单顶部，三档底图的 key 输入框各一个，填了哪个「底图状态」就亮哪个。
- 画面（回首页；宽屏、手机宽都行，只在空闲态拍）：先在地图上方那个「我现在在哪」下拉里选一次「图书馆」——图上就冒出那个「我」的图钉；接着把图钉拖到博雅居，松手后第一趟的楼序和步行时间跟着重算。两次动作连着做，中间不停顿。图钉只在画布 `#trip-map` 够高时出现（`markerVisible()` 里的 `boxTallEnough()` 要求 `getBoundingClientRect().height >= 200`），矮了压根不渲染，不是画错。2026-11-19 实测空闲态：1280 宽外层 340、里层 242.97；390 宽外层 400、里层 312.72——两档都够，图上都出针。对话一唤醒地图就收成扁带（104 / 132），那一档拍不出来，千万别在对话开着的时候拍这一镜。
- 顺序不能反过来：当天还没标过位置时图钉不出现（`markerVisible()` 要求 `plan.here` 有坐标），所以是「先选一栋楼、再拖」，不是「先拖、拖完才选」。别演成图钉凭空出现。
- 要点：内置地点只能隐藏（删了下次升级就分不清你在说哪个楼），自己加的点能删；坐标提示写着 0–950 与 0–1450，代表这是校园米制坐标而不是经纬度。key 存在本机数据目录的 `map_keys.json` 里，不上传，从环境变量来的那把只显示后四位。拖出来的点 40 米内有楼就记在那栋楼上，没有就是「自由位置」，落点同时是当天行程的起点。
- 旁白：楼叫什么、在哪儿、底下垫哪家的图，都是设置里的事。起点不用敲坐标，选一栋楼把图钉拖过去就行。地图接口是公开的，别人学校的底图写成一个 adapter 注册进去，底图按钮上就多一档。
- 本段从 35 秒涨到 43 秒（多了拖图钉那两下）：全片 4:50 → 4:58，仍在 5 分钟内；念的时候把最后两句并成一句走。

## 3:43–4:23 失败场景（评分里专门有这一项）

- 模型没连上：说话 → trace 自报「没有模型，这句按本地规则办的」；问「今天怎么安排」仍报出 2 趟、5 站、1044 米和头一趟楼序；行程和地图照常。
- 地点认不出：说「去西门的打印店取材料」→ 建单成功，但列进「没说地点」，不硬塞进行程。补地点也是一句话：「这件在图书馆」→ 它把楼名换成本机地点表里的 id 存下，这一件就进得了下一趟。楼名它认不出时（说「火星」）一个字都不写。
- 装不下：故意说一件截止在半小时后、又在远处的事 → 行程里明说塞不下，给「明天上午 / 提前出发」两个替代。

## 4:23–4:58 收尾

- 画面：设置里贴课表 → 行程立刻按新课表重排；再点「课表」→「选课表截图」选一张教务截图，等它把每节课抄进框里，核对后保存，行程跟着变。
- 旁白：数据都在本机一个 SQLite 文件和几个 JSON 里；模型可选，接云端一句三到五秒，不想联网就换本机 Ollama。
- 字卡：换一片校区放一份地点表，换底图按注册表接一家，两样都不用改代码。自研部分与第三方来源见计划书第 8 页。
