# 答辩口径卡

用法：评委问哪句，翻到哪条，先给一句话答案，再把证据递过去。证据都能当场打开，别背数字。

口径基准：`F:\nh-agent` HEAD `3e5e767` 的代码，行号按这一笔逐条核过（文件还会动，行号对不上时按函数名找，函数名没变过）。

## 1. 这跟普通的通知聚合 App 差在哪？

别人停在「把通知收进一个列表」，我们往下走一步：算出今天要走几趟、哪站先办，每站还给一句为什么是这个顺序。

证据：`GET /api/agent/plan` 的 `counts` 是 {{facts.trip_count}} 趟、{{facts.trip_stops}} 站、{{facts.trip_meters}} 米；页面抬头走路写 {{facts.trip_minutes}} 分钟，因为 `js/trip.js:357` 把两趟的分钟相加（{{facts.trip1_minutes}} 加 {{facts.trip2_minutes}}，按总里程折算 14.9）。行程说明里有「起点用最后一节课的立德楼，不用先回宿舍」（`application/trips.py:472`）。

## 2. 「智能体」是真在决策，还是关键词 if-else？

模型只决定调哪个工具、带什么参数、怎么把结果说成人话；站序、分钟数、每站理由都是规则算的，能复算、能对账。关键词匹配不出「先 `poi_near` 再 `plan_route` 比顺序」这种两步。

证据：入口 `agent_chat.chat_turn`（`application/agent_chat.py:109`），可用地点清单拼进提示词在同一个函数 `:134`；站序 `application/trips.py:103`（`:112` 最近邻、`:107` 起点为空时直接取第一个）；分钟 `application/route_tools.py:82` 与 `:84` 都除 `WALK_M_PER_MIN`；每站理由 `trips.py:308-325`。

## 3. 模型具体负责到哪一步，哪些是你们自己写的？

模型管三件：听懂那句话、挑工具和参数、把执行结果说成人话。剩下全是我们写的代码。

证据：`POST /api/agent/chat` 的 `trace` 三段——读、想、调，渲染在 `web_static/page.html:5810` 的 `agentTrace()`（按 `step.kind` 分标签，读那支在 `:5834`），默认摊开不用点（`:5820` `aria-expanded='true'`、`:5828` `list.hidden=false`）。改事闭环：发「把『去博雅居拿快递』挪到明天下午两点」，HTTP 200、`changed=true`、trace 里 `tool=reschedule`、`ok=True`、`detail=已改期`，`say` 是「已改好，『去博雅居拿快递』截止时间改到明天下午两点。」；落库在 `week` 桶、`deadline=2026-11-19T14:00:00`，当天 `/api/agent/plan` 里就没有博雅居了。

## 4. 排程为什么这么排，凭什么说顺路？

先按片区把手上的事分组，组内最近邻一站接一站，塞不进空档的单列。步速只有一个来源，70 米/分钟，注释写着含进楼、找教室、等电梯。

证据：`application/trips.py:19 WALK_M_PER_MIN = 70.0`；分组 `:192-196`（`:195` 按 `zone` 归档）；最近邻 `:103-112`；手排优先 `:119`，`:134` 把固定的先放、其余再交给 `_order_stops`；路线工具 `route_tools.py:10` 导入这个常量、`:82`/`:84` 除它、`:89` 的 `basis` 也念它。给模型的提示词也读同一个常量（f-string）——以前那里写死 75，模型嘴里和面板会对不上，`890dd41` 改掉了，`tests/test_application_agent_chat.py` 的 `test_prompt_quotes_the_same_walking_speed_as_the_tools` 锁着。**三处一个数：70。**

演示真值：{{facts.trip_count}} 趟、{{facts.trip_stops}} 站、{{facts.trip_meters}} 米、走路 {{facts.trip_minutes}} 分钟。第 1 趟 15:40 立德楼→立行楼→图书馆，{{facts.trip1_meters}} 米、{{facts.trip1_minutes}} 分钟；第 2 趟 16:30 第一餐厅→1 号楼，{{facts.trip2_meters}} 米、{{facts.trip2_minutes}} 分钟。把还书挪到明天之后：{{facts.trip_moved_stops}} 站、{{facts.trip_moved_meters}} 米、走路 {{facts.trip_moved_minutes}} 分钟。

## 5. 换一个学校能用吗？

改数据，不改代码。

证据：楼名、别名、片区在 `application/campus.py:40-70`（{{facts.poi_count_builtin}} 条，含武进楼）；坐标在 `web_static/js/campus-geo.json`，从 OpenStreetMap 换算（`campus.py:37` 指向它、`:128 load_pois` 读入）；数据目录里放一份 `campus_poi.json`，同 id 覆盖内置那条，写坏了当没写。

## 6. 手机端凭什么算做完？

390 宽重排成一列，底栏 72px 加安全区，行程里的站只留楼名，概览不再给行程让位（限 40vh、内部滚动）。本机 `127.0.0.1` 或 https 下有「装到桌面」，`web_static/js/pwa.js:22` 判 `isSecureContext` 与是否已安装。

边界照实说：安卓走局域网 http 只能往桌面加个快捷方式，浏览器不给装桌面的入口；仓库里有安卓工程（`android/`，{{facts.android_files}} 个文件），没打过包、真机没验过，全仓一个 `.apk` 都没有——别答「有 APK 能装」。

## 7. 断网了怎么办？

分两种地址，答案不一样：

- 本机 `127.0.0.1` 或 https：service worker 装得上，断网重开能出页面，页里标着「上次的排法 · 时间」（`js/trip.js:392`），底部一条通栏「没网了。这一页是上次打开时留下的，连上以后点「重试」才更新。」，整页只读、写不进去。
- 局域网 `http://电脑IP:端口`：浏览器不给 service worker（实测 `isSecureContext: false`），电脑一关手机就打不开。

数据请求一律失败，`/api/` 故意不缓存——旧数据装成新数据比打不开更糟。被问「地铁上能用吗」，答不能，要等到有网。

证据：`web_static/js/sw.js` 的 `SHELL` 只列外壳（首页、manifest、4 个图标、11 个脚本），`:20-21` 跳过 `/api/` 与非 GET；注册在 `page.html:3332`（`navigator.serviceWorker.register('/js/sw.js', …)`，只在 https 与本机地址）；浮条 `#net-bar` 固定在底部（`page.html:2098`），文案在 `page.html:3392`。

## 8. 哪些地方写死、写死在哪？

真决策只有一层：`agent_chat.chat_turn`（`agent_chat.py:109`）让模型决定调哪个工具与回复正文，可用地点清单也在那里拼进提示词（`:134`）。其余写死，逐条可核：

- 站序 `trips.py:103`：`:112 nxt = min(remaining, key=lambda item: _distance(cursor, item["place"]))`，`:107` 起点为空时直接取第一个。
- 分组 `trips.py:192`：`:195 zones.setdefault(str(stop["place"].get("zone") or "未分区"), []).append(stop)`；入口 `:224 _build_trip`。
- 手排优先 `trips.py:119`：`:134` 固定的先放，剩下交给 `_order_stops`。
- 每站理由 `trips.py:308-325`，五条固定文案：`:317` 从这里出发、`:318` 第一站没课表、`:322` 就在下课的这栋楼、`:323` 同一栋楼还有一件、`:324` 接着走 N 米比再跑一趟省一次往返。
- 分钟 `route_tools.py:82` 与 `:84` 除 `WALK_M_PER_MIN`（70，`trips.py:19`）。
- 地点与片区 `campus.py:40-70`，坐标另在 `campus-geo.json`。

## 9. 跟微信、钉钉的日程比，价值在哪？

它们替你记，我们把你记下的几件事排成一条走得完的线，每站带到点时间、米数，还有一句为什么先办这件。

证据：plan 每站带 `arrive`、米数和 `why`；`trips.py` 的 `_why` 只写算出来的事实，不编理由。

## 12. 演示包要不要联网？没有模型钥匙怎么办？

要联网，模型走云端接口。包里不带钥匙——`提交清单.md` 那两条写的就是「无 `llm.key`、无 `.env`、无 `data/`、无 `logs/`」和「这个包不带任何钥匙」。要真对话，自己把一把 key 写进解压后 `启动演示.cmd` 同目录。

没钥匙时对话按本地规则办，不是只会说读不懂：交代一件事真提一条待办，问还有几件没办报件数，问「今天怎么安排」真排一遍（{{facts.trip_count}} 趟、{{facts.trip_stops}} 站、{{facts.trip_meters}} 米、头一趟 15:40 从立德楼起走立行楼、图书馆），问「立德楼附近有什么」报 {{facts.poi_near_places}} 处地点、{{facts.poi_near_tasks}} 件未完，再列由近到远三处米数。只有模型才懂的那类话，它直说「这句我按本地规则读不懂」。

证据：本地规则全在 `agent_chat._no_model_turn`（`application/agent_chat.py:643`，规则体 `:649-742`），提事落库走 `_local_fallback`（`:592`）；两句自报是 `:624` 的 `_RULE_STEP` 与 `:625` 的 `_RULE_DUNNO`，读不懂时 `:742` 就回后者。

## 13. 有多少人在用？数字哪来的？

GitHub 发了 20 个版本（v1.0.0 → v1.1.0），累计下载 1639 次；单版最高 beta.2 460 次、v1.0.0 454 次、beta.12 200 次、beta.14 124 次。抖音两条演示视频播放 21.9 万、收藏 5284（1830 + 3454）。Gitee 镜像同步了 17 个版本，那边接口不给附件下载次数，所以只有一个下载数，不编第二个。

取数：`gh api repos/ExpertKT/notice-hub/releases --paginate` 拉全量，逐版本把附件 `download_count` 相加；Gitee 走 `https://gitee.com/api/v5/repos/ExpertKT/notice-hub-mirror/releases`（附件对象只有 `name` 和 `browser_download_url`，没有计数字段）。抖音那两条是作者后台的数。

被追问就照实划三条边：下载不等于在用；抖音的播放是「看见」，收藏才是「想留着用」；没埋点，所以没有留存率、日活这类数。

## 现场别说的三句

- 「完全离线可用」——局域网 http 下没有 service worker；本机或 https 下也只是外壳加只读快照。
- 「AI 全自动」——站序、分钟、每站理由都是规则算的，模型只挑工具。
- 「零配置换校区」——楼表、坐标表、片区常量都得对一遍。

## 不够硬的几条

1. 第 10 条：另一位队友的姓名学号还没给，写「待填」，别替人编。
2. 第 6 条：安卓 http 下只能加快捷方式，评委追「算不算装到手机上」，答不算；`android/` 有工程、没打包、真机没验过，别说有可装的 APK。
3. 第 7 条：目前要电脑开着、走本机或同一局域网；断网只剩只读快照。
4. 小程序：仓库有 `miniprogram/` 源码工程，只在开发者工具里验过，真机要换自己的 AppID 与 HTTPS 合法域名，别说成「有小程序能跑」。
5. `提交清单.md` 里那五项包数字（字节数、sha256 前 16 位、文件数、源码提交）等重出包后一次改准，现在别引用。
